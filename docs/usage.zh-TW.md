## 安裝與更新

[下載最新版本 →](https://github.com/yuxino/kiri/releases/latest)

| 平台 | 安裝方式 |
| --- | --- |
| macOS 14+ · Apple 晶片與 Intel | 開啟 Universal `.dmg`，將 Kiri 拖到「應用程式」。 |
| Windows 11 · x64 | 執行 `.exe` 安裝程式，或解壓縮 Portable ZIP 後執行 `kiri.exe`。 |
| Ubuntu 24.04 · x64 · GNOME / X11 | 下載 `.deb`，將實際檔名代入 `sudo apt install ./kiri_VERSION_amd64.deb`。 |

macOS 需要「螢幕與系統音訊錄製」權限；點擊提示還需要「輸入監控」，麥克風錄音需要 macOS 15+。應用程式尚未經 Apple 公證：若受到阻擋，請到「系統設定 → 隱私權與安全性 → 強制打開」。Windows 套件沒有 Authenticode 簽章，SmartScreen 可能顯示警告。

Linux：Wayland 擷取目前支援一台已連接的螢幕。MP4 錄影可透過本機 PulseAudio 或 PipeWire 音訊服務加入系統音訊與麥克風。尚不支援點擊提示。已儲存影片可做基本剪輯並匯出 MP4，進階影片效果尚不支援。設定與錄影控制見 [Linux 指南](linux.md)。

更新：macOS 與 Windows 安裝版使用「設定 → 關於 → 檢查更新」。Linux 與 Windows Portable 使用者請從 Releases 下載新套件。Portable 的設定與素材仍保存在 Windows 使用者設定檔內。

macOS Dock：「設定 → 在 Dock 中顯示」可立即切換 Dock 圖示並記住選擇。隱藏後仍可使用選單列圖示與截圖快速鍵。

## 語言

在「設定 → 一般 → 語言」選擇 English、简体中文、繁體中文、日本語、Deutsch、한국어 或 Français。選擇會立即套用到所有 Kiri 視窗，重啟後仍會保留；首次啟動時跟隨系統語言。介面語言不會變更 Linux OCR 已安裝的語言資料。

## 擷取

在 macOS 按 ⇧⌘A，Windows / Linux X11 按 Shift+Ctrl+A，再選取視窗或拖曳區域。Wayland 可使用「截圖」按鈕，或在桌面設定將 `kiri --capture` 綁定到快速鍵。支援的桌面也提供「設定 → 快捷鍵 → Wayland 桌面快速鍵」，讓桌面授權截圖、暫停/繼續與停止操作。Ubuntu 24.04 / GNOME 46 保留指令方式。

macOS、Windows 和 Linux 均可向 Kiri 執行檔傳入 `--capture`、`--record`、`--ocr`、`--library`，分別開啟截圖選區、錄影選區、文字辨識和主視窗；Kiri 已執行或尚未啟動時皆可使用。

選擇截圖、錄影或 OCR。截圖工具列也提供 QR Code 辨識。Enter 完成截圖，Esc 取消擷取。截圖會複製至剪貼簿並儲存到本機素材庫。macOS、Windows 與 X11 可在「設定 → 快捷鍵」點選按鍵欄位，直接按下要使用的按鍵，也可清除或還原預設值；錄影控制快速鍵僅在錄影時生效。

選擇標註工具前，點選截圖工具列的滑桿按鈕，選取區域邊緣會顯示可編輯的寬度與高度。數值為輸出像素，包含 Retina 螢幕。Enter 或離開輸入欄位套用數值；Esc 放棄目前輸入，再按一次 Esc 取消擷取。方向鍵調整一個像素，配合 Shift 調整十個。再點一次滑桿隱藏數值；開始標註後，滑桿用於外觀設定。

在 macOS 上，選取區域後若變更螢幕排列、解析度或縮放，請重新擷取再錄影。若錄影已暫停，請先停止並儲存。

輸入文字時，Ctrl/Cmd+Z 復原文字。一般文字、標籤和浮水印按 Enter 結束目前編輯，Shift+Enter 換行；序號說明按 Enter 換行。Ctrl/Cmd+Enter 可結束任何文字編輯。沒有文字輸入欄位、焦點在截圖畫布上時，Enter 完成截圖。Esc 先取消這次文字編輯，再按一次取消擷取。關閉已編輯的圖片時，若尚有未儲存變更，會提供儲存、捨棄或繼續編輯。

GNOME Wayland 首次擷取若沒有顯示權限對話框，請開啟素材庫，在錯誤橫幅中選擇「請求存取權限」，於 GNOME 對話框允許截圖後重試。Kiri 會捨棄用來授權的圖片。詳見 [Linux 指南](linux.md)。

錄影準備面板提供 MP4 / GIF、「開始錄影」和四個並排圖示：系統音訊、麥克風、滑鼠指標、點擊提示。開始後固定倒數 3 秒；GIF 為無聲錄影。面板依選取範圍與螢幕邊緣自動定位。

點擊麥克風旁的小箭頭選擇實際錄音裝置，不會更改系統預設裝置。所選裝置無法使用或中斷連線時會明確報錯，不會默默切換至其他麥克風。

## 捲動截圖

框選需要捲動的內容，在加入標註前點選截圖工具列的「捲動截圖」。可以從任意位置開始，照常向上或向下捲動；返回已擷取內容時不會重複加入。停下來閱讀不會結束截圖。點選「完成」複製並儲存；開始儲存前可按 Esc 取消。Enter 仍交給原應用程式處理。

點選「置頂」可一次完成截圖、複製、儲存並開啟置頂參考圖。如果參考圖無法開啟，已儲存的圖片仍會保留，可從完成卡中重試。出現「儲存已擷取區域」時，請先儲存這份部分結果，再從完成卡中置頂。

捲動截圖進行中，可用 `kiri --finish-scroll-capture` 執行與「完成」相同的完整儲存檢查，不會自動改為儲存部分結果。`kiri --cancel-scroll-capture` 可在儲存開始前取消。兩條指令只操作目前的工作階段，不會開始新的截圖。

擷取期間會持續標示選取範圍，並調暗範圍外的區域。點擊、滾輪與觸控板手勢會直接傳給原應用程式；這層提示不會改變選取範圍，也不會出現在儲存的圖片中。

預覽取自原始截圖，即時跟隨目前片段，並依小視窗寬度等比例顯示。截圖變長時，預覽中的文字不會跟著縮小。在預覽內上下捲動可查看內容，移開滑鼠後恢復跟隨。拖曳頂部標題即可移動小視窗；精簡控制列可拖曳狀態文字。小視窗會留在目前擷取的螢幕內，X11 下也會避開選取範圍。

捲動後，Kiri 會移除已識別的固定頂欄和底欄；未再次捲過的最外緣可能仍有陰影。若提示需要恢復，請捲回相關區域，再儲存完整圖片。

暫時接不上時，Kiri 會保留已連續拼接的結果，提示捲回已擷取內容。返回後再經過缺少的區域即可繼續。拖曳捲軸跳過、沒有顯示過的內容，需要重新捲過才能擷取。出現「儲存已擷取區域」時，點選它只儲存目前的部分結果，不會補齊缺少或不確定的內容。儲存失敗後可以重試，已有結果會保留。

支援 macOS、Windows 和 Linux X11，Wayland 暫不可用。macOS 的選取範圍須完整位於一個一般應用程式視窗內；擷取會鎖定該視窗，排除外部浮動視窗及同一應用程式的其他視窗。來源視窗移動、調整大小或無法使用時會停止擷取並保留進度。Windows 和 X11 仍擷取螢幕區域，不會自動排除外部浮動視窗，請將它們移出選取範圍。

大段空白、重複內容、水平捲動、縮放或頁面重新排版都可能使拼接暫停。X11 需要在選區外留出 220 × 76 控制項及少量間距；macOS、Windows 必要時會把不進入截圖的控制項放在選區內。達到圖片大小上限後，可儲存已擷取區域，再開始下一張。

## 截圖標註

已儲存圖片沿用截圖的標註操作：點工具或既有標註顯示對應選項，沒有選取內容時把空間留給圖片。長圖預設依視窗寬度顯示，較窄的圖片不會自動放大；可捲動瀏覽，並在底部縮放、符合寬度／視窗或恢復原始大小。雙指捏合或按住 Ctrl/Command 捲動可縮放，按住空白鍵拖動畫面。檢視縮放不會改變儲存的圖片尺寸。

選取既有標註即可修改樣式。馬賽克支援自由畫筆、矩形和橢圓，可選像素或模糊效果並調整強度。點擊浮水印（W）後直接在圖片中輸入文字，可調整平鋪浮水印的不透明度、角度和間距；儲存後仍可再次編輯。

截圖屬性預設靠近主工具列放置，選取標註不會觸發自動避讓。可拖曳小把手，獨立移動工具列和屬性面板；聚焦把手後，方向鍵每次移動 2 像素，配合 Shift 移動 10 像素。調整選取範圍或切換工具會保留這次的手動位置，新截圖恢復自動定位；屬性面板會避開主工具列和螢幕邊緣。收起屬性後，面板保持關閉，直到再次從主工具列開啟。

文字（T）、序號標註（N）和標籤氣泡（B）在截圖與圖片編輯器的工具列上各有獨立按鈕。選擇序號標註後，點擊放置並直接在圖片中輸入說明，Return 換行；可分別拖曳序號和透明說明框，並調整大小、顏色與實心／空心樣式。

已有文字、序號、標籤氣泡和浮水印單擊選取、拖曳移動、雙擊編輯。選取標註後按 `Delete` 或退格鍵刪除，也可點擊「刪除標註」；`⌘Z` / `Ctrl+Z` 復原。輸入文字時，刪除鍵只刪除文字。

使用矩形、線條或箭頭時，可直接在空白處拖曳下一個圖形，單擊空白只取消選取。文字、序號和標籤選取既有標註時，仍需先取消選取，再放置下一個。正在編輯文字時，第一次空白操作只結束編輯並取消選取，下一次才放置標註；輸入法候選字確認仍按原生方式處理。畫筆和馬賽克可連續繪製。點擊畫布結束浮水印輸入，再次編輯會重用原浮水印。

在截圖畫布上按右鍵：正在編輯文字時提交文字，正在拖曳時取消尚未完成的操作，其餘時候取消物件選取並切回「選取」。已完成標註、截圖範圍和復原歷史都會保留。尚未開始標註時，右鍵先清除選取範圍，再按右鍵退出截圖。輸入欄位仍使用原生右鍵選單。

標註依加入順序堆疊。後畫的馬賽克會處理先前的文字、圖形與浮水印；之後加入的標註顯示在其上方。移動或編輯標註會保留原來的層位。

## 參考圖與取色

連按兩下截圖選取範圍的空白處也能完成截圖，既有文字仍可連按兩下編輯。工具列的圖釘可儲存並置頂，完成卡上的「置頂」也能開啟參考圖。拖曳圖片可移動視窗，拖曳右下角可等比例調整視窗大小，移入或聚焦控制項後可取消置頂或關閉。

長圖從頂部依可讀寬度開啟，超出部分可捲動查看。滾輪與雙指滑動用於瀏覽；雙指捏合或按住 Ctrl/Command 捲動，圍繞滑鼠位置縮放圖片，視窗大小保持不變。按住空白鍵拖曳或按住滑鼠中鍵拖曳可平移圖片，直接拖曳仍是移動視窗。移入或鍵盤聚焦後顯示縮放列，點選比例可選「符合寬度」「符合視窗」「原始大小」。Ctrl/Command 配合 +/− 縮放，配合 0 符合視窗，配合 1 恢復原始像素密度；Esc 或 Ctrl/Command+W 關閉參考圖。檢視不會改變已儲存圖片。

截圖模式下，懸停可放大查看原始像素、座標和 HEX 色值；按 `⌘C`（macOS）或 `Ctrl+C` 複製色值，選取範圍會保留。開始標註後放大鏡隱藏。

## GIF 轉換

在素材庫中將 MP4 轉成 GIF 時，Kiri 會先檢查影片能否解碼，再開始編碼。檢查或轉換時可按「取消」；多個工作可按「全部取消」。取消會保留原始影片，最後儲存到素材庫的階段不能取消。

## 素材庫與回饋

點擊「多選素材」後逐項勾選或全選，再移到垃圾桶；一般點擊仍直接開啟素材。垃圾桶支援批次還原，清空前會在主視窗內確認。重新命名會更新實際檔名並保留類型；右鍵「複製檔案」可貼到資料夾，原有「複製」用於貼上圖片。

回報問題前，可在「設定 → 關於」複製應用程式、系統與顯示器資訊，不包含截圖、憑證或個人路徑。

「設定 → 關於」也提供「打開檔案夾」和 GitHub 入口。可開啟設定、日誌目錄；Windows 也可開啟錯誤日誌和系統暫存檔案夾。這些入口只開啟目錄，不會清理檔案。

## 隱私

素材與媒體處理留在本機。遠端 OCR 可選，每次上傳前都會詢問。可編輯截圖會在本機保留原始圖片，包含被標註遮住的像素。請閱讀 [隱私政策](privacy/en.md)。
