## 安装与更新

[下载最新版本 →](https://github.com/yuxino/kiri/releases/latest)

| 平台 | 安装方式 |
| --- | --- |
| macOS 14+ · Apple 芯片与 Intel | 打开 Universal `.dmg`，将 Kiri 拖入“应用程序”。 |
| Windows 11 · x64 | 运行 `.exe` 安装包，或解压 Portable ZIP 后运行 `kiri.exe`。 |
| Ubuntu 24.04 · x64 · GNOME / X11 | 下载 `.deb`，执行 `sudo apt install ./kiri_VERSION_amd64.deb`，文件名替换为实际下载的版本。 |

macOS 需要“屏幕与系统音频录制”权限；点击高亮还需要“输入监控”，麦克风录制需要 macOS 15+。应用未经过 Apple 公证，若被拦截，请在“系统设置 → 隐私与安全性 → 仍要打开”中放行。Windows 安装包未经过 Authenticode 签名，SmartScreen 可能提示警告。

Linux：Wayland 捕获支持连接一台显示器；MP4 录屏可通过本地 PulseAudio 或 PipeWire 音频服务录制系统声音和麦克风，暂不支持点击高亮；已保存的视频支持基础剪辑与 MP4 导出，暂不支持高级视频特效。配置与录屏控制方式见 [Linux 指南](linux.md)。

更新：macOS 与 Windows 安装版在打开主面板时检查更新，「设置」旁的「有更新」表示有新版本，可在“设置 → 关于”下载和安装，也可手动检查；Linux 与 Windows 绿色版从 Releases 下载新版安装包。绿色版的设置和素材仍保存在 Windows 用户目录中。

macOS Dock：设置中的「在 Dock 中显示」会立即切换图标显示，并记住选择；隐藏后仍可使用菜单栏和截图快捷键。

## 永久删除素材

在素材菜单中选择「永久删除」，或选中多个素材后，在网格上方的操作栏中点击
「永久删除（数量）」。红色按钮会先要求确认，确认后无法撤销。「移到回收站」
仍用于可恢复的删除；永久删除所选素材无需清空回收站。

## 语言

在「设置 → 通用 → 语言」中选择 English、简体中文、繁體中文、日本語、Deutsch、한국어 或 Français。选择会应用到每个已打开的 Kiri 窗口，重启后仍会保留；首次启动跟随系统语言。界面语言不会改变 Linux 已安装的 OCR 语言数据。

## 截图与录屏

按 ⇧⌘A（macOS）或 Shift+Ctrl+A（Windows / Linux X11），点击窗口或拖出一个区域。Wayland 使用“截图”按钮，或在桌面设置中绑定 `kiri --capture`。支持该接口的桌面还可以通过设置 → 通用 → Wayland 桌面快捷键，由桌面授权并分配截图、暂停/继续和停止的按键。Ubuntu 24.04 / GNOME 46 仍使用命令快捷键。

选择截图、录屏或 OCR。截图工具栏也提供「识别二维码」。Enter 确认截图，Esc 取消捕获。截图会复制到剪贴板并保存在本地素材库。macOS、Windows 和 X11 可在设置中修改截图快捷键。

选择标注工具前，点击截图工具栏的滑杆按钮，选区边上会显示可编辑的宽高标签。数值以输出像素为单位，Retina 屏幕也一样。Enter 或离开输入框应用尺寸；Esc 放弃当前输入，再按一次取消捕获。上下方向键每次调整一个像素，配合 Shift 调整十个。再次点击滑杆可收起标签。开始标注后，滑杆按钮仍用于展开样式控件。

macOS 上，选区后若更改显示器布局、分辨率或缩放，请重新截图选择区域，再开始录制；若录屏已暂停，请先停止并保存。

输入标注文字时，Ctrl/Cmd+Z 撤销文字，Shift+Enter 换行。Esc 先退出本次文字编辑，再按一次取消捕获。关闭已保存图片的编辑器时，如有未保存修改，会询问保存、放弃或继续编辑。

在 GNOME Wayland 上，如果首次截图没有出现授权窗口，请打开 Kiri 素材库，在错误提示中点击请求授权。在 GNOME 弹窗中允许截图，然后重新发起截图；授权时产生的图片不会进入 Kiri。详见 [Linux 指南](linux.md)。

录屏准备面板提供 MP4 / GIF、「开始录制」和四个平铺图标：系统声音、麦克风、鼠标指针、点击高亮。点击开始后固定倒计时 3 秒；GIF 为无声录制。面板按选区和屏幕边缘自动定位。

点击麦克风旁的小箭头选择实际录音设备，不会更改系统默认设备。所选设备不可用或断开时会明确报错，不会悄悄切换到其他麦克风。

macOS 与 Windows 的录屏控制条跟随选区，靠近屏幕边缘会自动避让；可以拖动当次控制条，下次捕获会重新按选区定位。暂停后保留已录时长，继续录制时接着计时。旧版 Windows 仍可能显示系统提供的整屏捕获边框。Linux 继续使用托盘或命令控制录屏。

## 截图标注

选中已有标注即可修改样式。马赛克支持自由画笔、矩形和椭圆，可选像素或模糊效果并调整强度。点击水印（W）后直接在图片中输入文字，可选单处或平铺，调整不透明度、角度和间距；保存后仍可再次编辑。

文字（T）、序号标注（N）和标签气泡（B）在截图与图片编辑器的工具栏上各有独立按钮。选择序号标注后，点击放置并直接在画布中输入说明，回车换行；直接拖动序号或透明说明框即可分别移动，编辑时可拖动说明框的边框；大小、颜色和实心／空心样式都可调整。

已有文字、序号、标签气泡和水印单击选中、拖动移动、双击编辑。选中标注后按 `Delete` 或退格键删除，也可点击「删除标注」；`⌘Z` / `Ctrl+Z` 撤销。输入文字时，删除键只删除文字。

正在输入文字、序号说明或标签时，点空白先结束输入并取消选中，下一次操作才使用当前工具。文字和形状工具选中已有标注时，也先点空白取消选中，再创建下一条。工具保持选中，画笔与马赛克仍可连续绘制。水印点画布结束输入，再次编辑会复用原水印。

标注按添加顺序叠放，后画的马赛克会处理此前的文字、图形和水印；之后添加的标注显示在其上方。移动或编辑已有标注保留层位。

## 参考图与取色

双击截图选区内的空白处也能完成截图，已有文字仍可双击编辑。点击截图工具栏的图钉可保存并置顶，完成卡上的「置顶」也能打开参考图；参考图带有细黑色圆角边框；拖动图片移动，拖动右下角等比例缩放，移入后可取消置顶或关闭。

截图模式下，悬停可放大查看原始像素、坐标和 HEX 色值；按 `⌘C`（macOS）或 `Ctrl+C` 复制色值，选区会保留。开始标注后放大镜隐藏。

## GIF 转换

素材库中的 MP4 转 GIF 会先检查视频能否解码，再开始编码。检查或转换时可按「取消」，多个任务可按「全部取消」。取消会保留原始视频，最后保存到素材库的阶段不能取消。

## 素材库与反馈

点击「多选素材」后逐项勾选或全选，再移到回收站；普通点击仍直接打开素材。回收站支持批量恢复，清空时会先在主窗口内确认。重命名同时更新实际文件名并保留类型；右键「复制文件」可粘贴到文件夹，原有「复制」用于粘贴图片。

反馈问题前，可在「设置 → 关于」点击「复制信息」，附上应用、系统和显示器信息；其中不包含截图、凭据或个人路径。

「设置 → 关于」还提供「打开文件夹」和 GitHub 入口。可打开设置、日志目录；Windows 也可打开错误日志和系统临时文件夹。这些入口只打开目录，不会清理文件。

## 隐私

素材与媒体处理都留在本机。远程 OCR 可选，每次上传前都会询问。可编辑截图会在本地保留源图，其中仍可能包含被标注遮住的内容。详见[隐私说明](privacy/zh-CN.md)。
