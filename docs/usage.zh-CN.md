## 安装与更新

[下载最新版本 →](https://github.com/yuxino/kiri/releases/latest)

| 平台 | 安装方式 |
| --- | --- |
| macOS 14+ · Apple 芯片与 Intel | 打开 Universal `.dmg`，将 Kiri 拖入“应用程序”。 |
| Windows 11 · x64 | 运行 `.exe` 安装包，或解压 Portable ZIP 后运行 `kiri.exe`。 |
| Ubuntu 24.04 · x64 · GNOME / X11 | 下载 `.deb`，执行 `sudo apt install ./kiri_VERSION_amd64.deb`，文件名替换为实际下载的版本。 |

macOS 需要“屏幕与系统音频录制”权限；点击高亮还需要“输入监控”，麦克风录制需要 macOS 15+。应用未经过 Apple 公证，若被拦截，请在“系统设置 → 隐私与安全性 → 仍要打开”中放行。Windows 安装包未经过 Authenticode 签名，SmartScreen 可能提示警告。

Linux：Wayland 捕获支持连接一台显示器；MP4 录屏可通过本地 PulseAudio 或 PipeWire 音频服务录制系统声音和麦克风，暂不支持点击高亮；已保存的视频支持基础剪辑与 MP4 导出，暂不支持高级视频特效。配置与录屏控制方式见 [Linux 指南](linux.md)。

更新：macOS 与 Windows 安装版在打开主面板时检查更新，「设置」旁的「有更新」表示有新版本，可在“设置 → 关于”下载和安装，也可手动检查；Linux 与 Windows 绿色版从 Releases 下载新版安装包。绿色版的设置和素材仍保存在 Windows 用户目录中。

macOS Dock：设置中的「在 Dock 中显示」会立即切换图标显示，并记住选择；隐藏后仍可使用菜单栏和截图快捷键。

## 永久删除素材

在素材菜单中选择「永久删除」，或选中多个素材后，在网格上方的操作栏中点击
「永久删除（数量）」。红色按钮会先要求确认，确认后无法撤销。「移到回收站」
仍用于可恢复的删除；永久删除所选素材无需清空回收站。

## 语言

在「设置 → 通用 → 语言」中选择 English、简体中文、繁體中文、日本語、Deutsch、한국어 或 Français。选择会应用到每个已打开的 Kiri 窗口，重启后仍会保留；首次启动跟随系统语言。界面语言不会改变 Linux 已安装的 OCR 语言数据。

## 截图与录屏

按 ⇧⌘A（macOS）或 Shift+Ctrl+A（Windows / Linux X11），点击窗口或拖出一个区域。Wayland 使用“截图”按钮，或在桌面设置中绑定 `kiri --capture`。支持该接口的桌面还可以通过设置 → 快捷键 → Wayland 桌面快捷键，由桌面授权并分配截图、暂停/继续和停止的按键。Ubuntu 24.04 / GNOME 46 仍使用命令快捷键。

macOS、Windows 和 Linux 均可向 Kiri 可执行文件传入 `--capture`、`--record`、`--ocr`、`--library`，分别打开截图选区、录屏选区、文字识别和主窗口；Kiri 已运行或尚未启动时都可使用。

选择截图、录屏或 OCR。截图工具栏也提供「识别二维码」。Enter 确认截图，Esc 取消捕获。截图会复制到剪贴板并保存在本地素材库。

### 快捷键

「设置 → 快捷键」集中管理全局快捷键，并提供应用内按键速查。
macOS、Windows 和 X11 用户可点击操作右侧的按键框，按下想用的按键或组合。
F1–F24、媒体键，以及包含 Control、Alt/Option 或 Command/Windows 的组合，在系统
支持且可用时直接保存。其他单键或仅搭配 Shift 的组合会先预览，需要点击「使用此按键」
确认，因为它们也会影响其他应用的输入或导航；录屏控制按键只在录制期间产生这种影响。
修改成功前，原绑定保持不变。

macOS 普通快捷键不需要「输入监控」权限。媒体键使用拦截式事件监听，需要已有的
「辅助功能」授权；未授权时会明确报错并保留原绑定，不弹窗申请，也不更改权限。

Esc 取消。Tab 或 Shift+Tab 离开录入；已有待确认按键时，可用 Tab 移到确认按钮。
搭配 Control、Alt/Option 或 Command/Windows 时，Esc 和 Tab 本身也可录入。
单独按修饰键不会设置绑定。清除按钮解除绑定；修改或清除后可直接恢复默认。

四个「启动操作」在 Kiri 运行期间保持可用：

| 操作 | macOS | Windows / Linux X11 |
| --- | --- | --- |
| 截图 | ⇧⌘A | Shift+Ctrl+A |
| 录屏 | ⌥⇧⌘R | Alt+Shift+Ctrl+R |
| 识别文字 | ⌥⇧⌘O | Alt+Shift+Ctrl+O |
| 显示主窗口 | ⌥⇧⌘L | Alt+Shift+Ctrl+L |

两个「录制过程中」操作可在其他应用中控制当前录屏，暂停期间也有效：

| 操作 | macOS | Windows / Linux X11 |
| --- | --- | --- |
| 暂停/继续录制 | ⌥⇧⌘P | Alt+Shift+Ctrl+P |
| 停止并保存录屏 | ⌥⇧⌘S | Alt+Shift+Ctrl+S |

Kiri 在正式开始录制时注册这两个原生按键，进入停止保存阶段或录制失败时释放；
空闲、选择区域和倒计时期间不会占用。若录屏按键不可用，录制会继续并提示问题；
可先使用 macOS/Windows 控制浮窗或托盘菜单暂停、停止，再到「设置 → 快捷键」更换组合。

录屏和识别文字快捷键会进入对应模式的选区界面。录屏仍需点击开始并经过倒计时，
远程 OCR 仍需确认。已有截图按键会保留；若与新预设重复，对应新操作会暂不分配按键。
重复或不可用的组合不会替换原按键。系统注册无法检测其他应用内部的全部快捷键；
若影响常用操作，请换一个组合。

Wayland 的按键仍由桌面管理，可在系统键盘设置中分别绑定 `kiri --capture`、
`kiri --record`、`kiri --ocr`、`kiri --library`；录屏控制使用
`kiri --toggle-recording-pause` 和 `kiri --stop-recording`。可选的 Portal 设置仍提供截图、
暂停/继续和停止三个操作。这两个录屏命令只作用于正在进行的录制，但桌面可能在
Kiri 空闲时仍占用对应按键；Kiri 无法在两次录屏之间释放桌面管理的绑定。

选择标注工具前，点击截图工具栏的滑杆按钮，选区边上会显示可编辑的宽高标签。数值以输出像素为单位，Retina 屏幕也一样。Enter 或离开输入框应用尺寸；Esc 放弃当前输入，再按一次取消捕获。上下方向键每次调整一个像素，配合 Shift 调整十个。再次点击滑杆可收起标签。开始标注后，滑杆按钮仍用于展开样式控件。

macOS 上，选区后若更改显示器布局、分辨率或缩放，请重新截图选择区域，再开始录制；若录屏已暂停，请先停止并保存。

输入文字时，Ctrl/Cmd+Z 撤销文字。普通文字、标签和水印按 Enter 结束当前编辑，Shift+Enter 换行；序号说明按 Enter 换行。Ctrl/Cmd+Enter 可结束任意文字编辑。没有文字输入框、焦点在截图画布上时，Enter 完成截图。Esc 先取消本次文字编辑，再按一次取消捕获。关闭已保存图片的编辑器时，如有未保存修改，会询问保存、放弃或继续编辑。

在 GNOME Wayland 上，如果首次截图没有出现授权窗口，请打开 Kiri 素材库，在错误提示中点击请求授权。在 GNOME 弹窗中允许截图，然后重新发起截图；授权时产生的图片不会进入 Kiri。详见 [Linux 指南](linux.md)。

录屏准备面板提供 MP4 / GIF、「开始录制」和四个平铺图标：系统声音、麦克风、鼠标指针、点击高亮。点击开始后固定倒计时 3 秒；GIF 为无声录制。面板按选区和屏幕边缘自动定位。

点击麦克风旁的小箭头选择实际录音设备，不会更改系统默认设备。所选设备不可用或断开时会明确报错，不会悄悄切换到其他麦克风。

macOS 与 Windows 的录屏控制条跟随选区，靠近屏幕边缘会自动避让，出现时不会抢走键盘焦点；可以拖动当次控制条，下次捕获会重新按选区定位。暂停后保留已录时长，继续录制时接着计时。使用设置好的录屏快捷键、控制条按钮或托盘菜单操作；控制条没有内置的裸空格/Esc 录屏监听；若主动确认把单键设为录屏快捷键，则按该绑定生效。主动聚焦的按钮仍支持标准的空格/Enter 激活。Esc 仍可取消捕获与倒计时。旧版 Windows 仍可能显示系统提供的整屏捕获边框。Linux 使用 X11 原生快捷键、Wayland 桌面快捷键、托盘或命令控制录屏。

## 滚动截图

框选需要滚动的内容，在添加标注前点击截图工具栏的「滚动截图」。可以从任意位置开始，照常向上或向下滚动；返回已截内容时不会重复添加。停下来阅读不会结束截图。点击「完成」复制并保存；开始保存前可按 Esc 取消。Enter 仍交给原应用处理。

点击「置顶」可一次完成截图、复制、保存并打开置顶参考图。如果参考图未能打开，已保存的图片仍会保留，可从完成卡中重试。出现「保存已截区域」时，请先保存这份部分结果，再从完成卡中置顶。

滚动截图进行中，可用 `kiri --finish-scroll-capture` 执行与「完成」相同的完整保存检查，不会自动改为保存部分结果。`kiri --cancel-scroll-capture` 可在保存开始前取消。两条命令只操作当前会话，不会启动新的截图。

截图期间会持续标出选区，并调暗选区外的区域。点击、滚轮和触控板手势会直接传给原应用；这层提示不会改变选区，也不会出现在保存的图片中。

预览取自原始截图，实时跟随当前片段，并按小窗宽度等比显示。截图变长时，预览中的文字不会跟着缩小。在预览内上下滚动可查看内容，移开鼠标后恢复跟随。拖动顶部标题即可移动小窗；精简控制条可拖动状态文字。小窗会留在当前截图屏幕内，X11 下也会避开截图选区。

滚动后，Kiri 会移除已识别的固定顶栏和底栏；未再次滚过的最外缘可能仍有阴影。若提示需要恢复，请滚回相关区域，再保存完整图片。

暂时接不上时，Kiri 会保留已连续拼接的结果，提示滚回已截内容。返回后再经过缺失区域即可继续。拖动滚动条跳过、没有显示过的内容，需要重新滚过才能截取。出现「保存已截区域」时，点击它只保存当前部分结果，不会补齐缺失或不确定的内容。保存失败后可以重试，已有结果会保留。

支持 macOS、Windows 和 Linux X11，Wayland 暂不可用。macOS 的选区须完整位于一个普通应用窗口内；采集会锁定该窗口，排除外部浮窗以及同一应用的其他窗口。来源窗口移动、调整大小或不可用时会停止采集并保留进度。Windows 和 X11 仍截取屏幕区域，不会自动排除外部浮窗，请将它们移出选区。

大段空白、重复内容、横向滚动、缩放或页面重新排版都可能使拼接暂停。X11 需要在选区外留出 220 × 76 控件和少量间距；macOS、Windows 必要时会把不进入截图的控件放在选区内。达到图片大小上限后，可保存已截区域，再开始下一张。

## 截图标注

已保存图片沿用截图的标注操作：点工具或已有标注显示对应选项，没有选中内容时把空间留给图片。长图默认按窗口宽度显示，较窄的图片不会自动放大；可滚动浏览，并在底部缩放、适应宽度／窗口或恢复原始大小。双指捏合或按住 Ctrl/Command 滚动可缩放，按住空格拖动画面。查看时的缩放不会改变保存的图片尺寸。

选中已有标注即可修改样式。马赛克支持自由画笔、矩形和椭圆，可选像素或模糊效果并调整强度。点击水印（W）后直接在图片中输入文字，可调整平铺水印的不透明度、角度和间距；保存后仍可再次编辑。

截图属性默认靠近主工具栏放置，选中标注不会触发自动避让。可拖动小把手，独立移动工具栏和属性面板；聚焦把手后，方向键每次移动 2 像素，配合 Shift 移动 10 像素。调整选区或切换工具会保留当次手动位置，新截图恢复自动定位；属性面板会避让主工具栏和屏幕边缘。点击「收起属性」后，面板保持关闭，直到再次从主工具栏打开。

文字（T）、序号标注（N）和标签气泡（B）在截图与图片编辑器的工具栏上各有独立按钮。选择序号标注后，点击放置并直接在画布中输入说明，回车换行；直接拖动序号或透明说明框即可分别移动，编辑时可拖动说明框的边框；大小、颜色和实心／空心样式都可调整。

已有文字、序号、标签气泡和水印单击选中、拖动移动、双击编辑。选中标注后按 `Delete` 或退格键删除，也可点击「删除标注」；`⌘Z` / `Ctrl+Z` 撤销。输入文字时，删除键只删除文字。

使用矩形、线条或箭头时，可直接在空白处拖出下一条，单击空白只取消选中。文字、序号和标签选中已有标注时，仍需先取消选中，再放置下一条。正在编辑文字时，第一次空白手势只结束编辑并取消选中，下一次才放置标注；输入法候选确认仍按原生方式处理。画笔和马赛克可连续绘制。点击画布结束水印输入，再次编辑会复用原水印。

在截图画布上右键：正在编辑文字时提交文字，正在拖动时取消尚未完成的手势，其余时候取消对象选择并切回「选择」。已完成标注、截图范围和撤销历史都会保留。尚未开始标注时，右键先清除选区，再右键退出截图。输入框仍使用原生右键菜单。

标注按添加顺序叠放，后画的马赛克会处理此前的文字、图形和水印；之后添加的标注显示在其上方。移动或编辑已有标注保留层位。

## 参考图与取色

双击截图选区内的空白处也能完成截图，已有文字仍可双击编辑。点击截图工具栏的图钉可保存并置顶，完成卡上的「置顶」也能打开参考图。参考图带有细黑色圆角边框；拖动图片可移动窗口，拖动右下角可等比例调整窗口大小，移入或聚焦控件后可取消置顶或关闭。

长图从顶部按可读宽度打开，超出部分可滚动查看。滚轮和双指滑动用于浏览；双指捏合或按住 Ctrl/Command 滚动，围绕鼠标位置缩放图片，窗口大小保持不变。按住空格拖动或按住鼠标中键拖动可平移图片，直接拖动仍是移动窗口。移入或键盘聚焦后显示缩放条，点击比例可选「适应宽度」「适应窗口」「原始大小」。Ctrl/Command 配合 +/− 缩放，配合 0 适应窗口，配合 1 恢复原始像素密度；Esc 或 Ctrl/Command+W 关闭参考图。查看不会改变已保存图片。

截图模式下，悬停可放大查看原始像素、坐标和 HEX 色值；按 `⌘C`（macOS）或 `Ctrl+C` 复制色值，选区会保留。开始标注后放大镜隐藏。

## GIF 转换

素材库中的 MP4 转 GIF 会先检查视频能否解码，再开始编码。检查或转换时可按「取消」，多个任务可按「全部取消」。取消会保留原始视频，最后保存到素材库的阶段不能取消。

## 素材库与反馈

点击「多选素材」后逐项勾选或全选，再移到回收站；普通点击仍直接打开素材。回收站支持批量恢复，清空时会先在主窗口内确认。重命名同时更新实际文件名并保留类型；右键「复制文件」可粘贴到文件夹，原有「复制」用于粘贴图片。

反馈问题前，可在「设置 → 关于」点击「复制信息」，附上应用、系统和显示器信息；其中不包含截图、凭据或个人路径。

「设置 → 关于」还提供「打开文件夹」和 GitHub 入口。可打开设置、日志目录；Windows 也可打开错误日志和系统临时文件夹。这些入口只打开目录，不会清理文件。

## 隐私

素材与媒体处理都留在本机。远程 OCR 可选，每次上传前都会询问。可编辑截图会在本地保留源图，其中仍可能包含被标注遮住的内容。详见[隐私说明](privacy/zh-CN.md)。
