## 설치와 업데이트

[최신 버전 다운로드 →](https://github.com/yuxino/kiri/releases/latest)

| 플랫폼 | 설치 |
| --- | --- |
| macOS 14+ · Apple Silicon 및 Intel | Universal `.dmg`를 열고 Kiri를 응용 프로그램으로 드래그합니다. |
| Windows 11 · x64 | `.exe` 설치 프로그램을 실행하거나 Portable ZIP을 압축 해제하여 `kiri.exe`를 실행합니다. |
| Ubuntu 24.04 · x64 · GNOME / X11 | `.deb`를 다운로드하고 실제 파일 이름으로 `sudo apt install ./kiri_VERSION_amd64.deb`를 실행합니다. |

macOS에는 ‘화면 및 시스템 오디오 기록’ 권한이 필요합니다. 클릭 강조에는 ‘입력 모니터링’도 필요하고 마이크 녹음에는 macOS 15 이상이 필요합니다. 앱은 Apple 공증을 받지 않았습니다. 실행이 차단되면 ‘시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기’를 사용하세요. Windows 패키지에는 Authenticode 서명이 없어 SmartScreen 경고가 표시될 수 있습니다.

Linux: Wayland 캡처는 연결된 모니터 한 대를 지원합니다. MP4 녹화에는 로컬 PulseAudio 또는 PipeWire 오디오 서비스를 통해 시스템 소리와 마이크를 포함할 수 있습니다. 클릭 강조는 아직 지원하지 않습니다. 저장한 동영상의 기본 자르기와 MP4 내보내기는 지원하지만 고급 동영상 효과는 사용할 수 없습니다. 설정과 녹화 제어는 [Linux 안내](linux.md)를 참고하세요.

업데이트: macOS와 Windows 설치 버전은 ‘설정 → 정보 → 업데이트 확인’을 사용합니다. Linux와 Windows Portable 사용자는 Releases에서 새 패키지를 다운로드하세요. Portable 설정과 캡처 자료는 Windows 사용자 프로필에 보관됩니다.

macOS Dock: ‘설정 → Dock에 표시’는 Dock 아이콘을 즉시 바꾸고 선택을 기억합니다. 아이콘을 숨겨도 트레이와 캡처 단축키는 계속 사용할 수 있습니다.

## 언어

‘설정 → 일반 → 언어’에서 English, 简体中文, 繁體中文, 日本語, Deutsch, 한국어, Français를 선택하세요. 선택은 모든 Kiri 창에 즉시 적용되며 다시 시작해도 유지됩니다. 처음에는 시스템 언어를 따릅니다. 인터페이스 언어를 바꿔도 Linux에 설치된 OCR 언어 데이터는 바뀌지 않습니다.

## 캡처

macOS에서 ⇧⌘A, Windows / Linux X11에서 Shift+Ctrl+A를 누른 뒤 창을 선택하거나 영역을 드래그합니다. Wayland에서는 캡처 버튼을 사용하거나 데스크톱 설정에서 `kiri --capture`에 단축키를 지정하세요. 지원하는 데스크톱은 ‘설정 → 일반 → Wayland 데스크톱 단축키’에서 캡처, 일시 정지/재개, 중지 권한을 승인할 수 있습니다. Ubuntu 24.04 / GNOME 46에서는 명령 방식도 유지됩니다.

스크린샷, 녹화 또는 OCR을 선택합니다. 스크린샷 도구 모음에서는 QR 코드도 인식할 수 있습니다. Enter로 스크린샷을 완료하고 Esc로 캡처를 취소합니다. 스크린샷은 클립보드와 로컬 라이브러리에 저장됩니다. macOS, Windows, X11의 캡처 단축키는 설정에서 변경할 수 있습니다.

주석 도구를 고르기 전에 스크린샷 도구 모음의 슬라이더 버튼을 누르면 선택 영역 가장자리에 편집할 수 있는 너비와 높이가 나타납니다. Retina에서도 값은 출력 픽셀 기준입니다. Enter를 누르거나 입력란을 벗어나면 적용됩니다. Esc는 현재 입력을 버리고, 다시 누르면 캡처를 취소합니다. 방향키는 1픽셀, Shift와 함께 누르면 10픽셀씩 조절합니다. 슬라이더를 다시 누르면 값을 숨깁니다. 주석을 시작한 뒤에는 외관 설정에 사용됩니다.

macOS에서 영역 선택 후 모니터 배치, 해상도 또는 배율을 변경했다면 녹화 전에 다시 캡처하세요. 녹화가 일시 정지된 상태라면 먼저 중지하고 저장하세요.

주석 텍스트를 입력할 때 Ctrl/Cmd+Z는 텍스트를 실행 취소하며 Shift+Enter는 줄을 추가합니다. Esc는 먼저 텍스트 편집을 끝내고, 다시 누르면 캡처를 취소합니다. 저장된 이미지를 편집한 뒤 닫을 때 저장하지 않은 변경 사항이 있으면 저장, 버리기 또는 계속 편집을 선택할 수 있습니다.

GNOME Wayland에서 첫 캡처에 권한 대화 상자가 나타나지 않으면 라이브러리를 열고 오류 배너에서 접근 권한을 요청하세요. GNOME 대화 상자에서 스크린샷을 허용한 뒤 다시 캡처합니다. Kiri는 권한 승인에 사용한 이미지를 버립니다. [Linux 안내](linux.md)를 참고하세요.

녹화 준비 패널에는 MP4 / GIF, 시작 버튼과 시스템 소리, 마이크, 마우스 포인터, 클릭 강조 아이콘 네 개가 나란히 표시됩니다. 시작하면 항상 3초 카운트다운을 거치며 GIF는 소리 없이 녹화합니다. 패널은 선택 영역과 화면 가장자리에 맞춰 배치됩니다.

마이크 옆의 작은 화살표에서 실제 입력 장치를 선택할 수 있으며 시스템 기본 장치는 바뀌지 않습니다. 선택한 장치를 사용할 수 없거나 연결이 끊어지면 오류를 표시하고 다른 마이크로 자동 전환하지 않습니다.

## 스크롤 캡처

macOS, Windows 또는 Linux X11에서 스크린샷 영역을 선택한 다음, 주석을 추가하기 전에 **스크롤 캡처**를 선택하세요. 고정된 머리글, 바닥글, 사이드바를 제외하고 세로로 스크롤되는 내용만 선택하세요. 선택 영역 옆에 미리보기 패널을 위한 공간을 남겨야 합니다. 패널을 영역 밖에 배치할 수 없으면 선택 영역을 줄이세요. Wayland에서는 현재 사용할 수 없습니다.

원래 앱에서 천천히 아래로 스크롤하면 옆 패널에 연결이 확인된 이미지가 표시됩니다. 일치 확인이 멈추면 이미 캡처한 내용까지 조금 위로 돌아간 뒤 다시 아래로 진행하세요. 반복되는 내용, 애니메이션, 창 이동이나 배율 변경으로 연결하지 못할 수 있습니다. Kiri는 고정 막대를 자동으로 제거하거나 대신 스크롤하지 않습니다.

**완료**를 누르면 일반 스크린샷과 같은 흐름으로 복사하고 저장합니다. 원래 앱에서도 **Esc**로 취소할 수 있습니다. **Enter**로 완료하려면 미리보기 패널에 포커스가 있어야 하며, 설정한 캡처 단축키를 다시 누르면 패널에 포커스를 옮깁니다. 마지막 부분을 연결할 수 없으면 **계속 조정**하거나 **캡처한 부분 저장**을 명시적으로 선택하세요. 출력은 각 변 8192픽셀, 총 32 MiPixels(33,554,432픽셀)로 제한됩니다. 한도에 도달해도 확인된 부분은 유지되며 저장 여부를 선택할 수 있습니다.

## 스크린샷 주석

기존 주석을 선택하면 스타일을 변경할 수 있습니다. 모자이크는 자유 그리기, 사각형, 타원을 지원하며 픽셀 또는 흐림 효과와 강도를 조절할 수 있습니다. 워터마크(W)를 선택해 이미지에 직접 입력하고 단일 또는 타일 배치, 불투명도, 각도, 간격을 조절하세요. 저장한 뒤에도 다시 편집할 수 있습니다.

글자(T), 번호 주석(N), 라벨 말풍선(B)은 스크린샷과 이미지 편집기의 도구 모음에 각각 독립된 버튼이 있습니다. 번호 주석을 선택하고 클릭해 배치한 뒤 이미지에서 설명을 직접 입력하세요. Return으로 줄을 바꾸고, 번호와 투명한 설명 상자를 따로 이동하며 크기, 색상, 채움 또는 윤곽 스타일을 조절할 수 있습니다.

기존 텍스트, 번호 주석, 라벨과 워터마크는 클릭하여 선택하고, 드래그하여 이동하며, 두 번 클릭하여 편집합니다. 선택한 주석은 `Delete` 또는 `Backspace` 키나 **주석 삭제**로 삭제하고 `⌘Z` / `Ctrl+Z`로 실행 취소할 수 있습니다. 텍스트 입력 중에는 글자만 삭제됩니다.

글자, 번호 설명 또는 라벨을 입력할 때 빈 곳에서 처음 조작하면 입력과 선택을 끝내고, 다음 조작에서 현재 도구를 사용합니다. 글자나 도형 도구로 기존 주석을 선택한 경우에도 먼저 빈 곳에서 선택을 해제한 뒤 새 주석을 만듭니다. 도구는 계속 선택되며 펜과 모자이크는 연속으로 그릴 수 있습니다. 워터마크 입력 중 캔버스를 클릭하면 입력을 끝내고, 다시 편집할 때 같은 워터마크를 사용합니다.

주석은 추가한 순서대로 쌓입니다. 나중에 그린 모자이크는 앞서 만든 글자, 도형, 워터마크에 적용되고 그 뒤에 추가한 주석은 위에 표시됩니다. 이동하거나 편집해도 순서는 유지됩니다.

## 참고 이미지와 색상

스크린샷 선택 영역의 빈 곳을 두 번 클릭해도 완료할 수 있습니다. 기존 텍스트는 두 번 클릭하여 편집합니다. 도구 모음의 핀으로 저장하고 고정하거나 완료 카드의 고정을 사용할 수 있습니다. 이미지를 드래그하여 이동하고 오른쪽 아래 모서리로 비율을 유지하며 크기를 조절하세요. 마우스를 올리면 고정 해제와 닫기가 나타납니다.

스크린샷 모드에서 마우스를 올리면 원본 픽셀, 좌표 및 HEX 색상 값을 확대해 볼 수 있습니다. macOS에서는 `⌘C`, 다른 환경에서는 `Ctrl+C`로 색상을 복사하며 선택 영역은 유지됩니다. 주석을 시작하면 돋보기가 숨겨집니다.

## GIF 변환

라이브러리에 저장한 MP4를 GIF로 변환할 때 Kiri는 먼저 동영상 디코딩을 확인한 뒤 GIF 인코딩을 시작합니다. 확인과 변환 중에 취소할 수 있으며 여러 작업은 한꺼번에 취소할 수 있습니다. 원본 동영상은 유지됩니다. 마지막 라이브러리 저장 단계가 시작된 뒤에는 취소할 수 없습니다.

## 라이브러리와 의견 보내기

여러 항목 선택에서 개별 항목 또는 전체를 선택하여 휴지통으로 옮길 수 있으며, 일반 클릭은 항목을 엽니다. 휴지통은 일괄 복원을 지원하고 비우기 전에 주 창에서 확인합니다. 이름 변경은 파일 형식을 유지하면서 실제 파일명도 바꿉니다. 우클릭 메뉴의 파일 복사는 폴더에 붙여넣을 때 쓰고, 일반 복사는 이미지를 붙여넣습니다.

문제를 신고할 때 설정 → 정보에서 앱, 시스템, 화면 정보를 복사할 수 있습니다. 캡처, 인증 정보, 개인 경로는 포함되지 않습니다.

설정의 앱 정보에서 설정·로그 폴더와 GitHub를 열 수 있습니다. Windows에서는 오류 로그와 시스템 임시 폴더도 열 수 있습니다. 이 작업은 파일을 삭제하지 않습니다.

## 개인정보

캡처 자료와 미디어 처리는 로컬에 유지됩니다. 원격 OCR은 선택 사항이며 업로드할 때마다 확인합니다. 편집 가능한 스크린샷은 원본 이미지도 로컬에 보관하며 주석으로 가린 픽셀도 포함됩니다. [개인정보 처리방침](privacy/en.md)을 읽어 주세요.
