## 설치와 업데이트

[최신 버전 다운로드 →](https://github.com/yuxino/kiri/releases/latest)

| 플랫폼 | 설치 |
| --- | --- |
| macOS 14+ · Apple Silicon 및 Intel | Universal `.dmg`를 열고 Kiri를 응용 프로그램으로 드래그합니다. |
| Windows 11 · x64 | `.exe` 설치 프로그램을 실행하거나 Portable ZIP을 압축 해제하여 `kiri.exe`를 실행합니다. |
| Ubuntu 24.04 · x64 · GNOME / X11 | `.deb`를 다운로드하고 실제 파일 이름으로 `sudo apt install ./kiri_VERSION_amd64.deb`를 실행합니다. |

macOS에는 ‘화면 및 시스템 오디오 기록’ 권한이 필요합니다. 클릭 강조에는 ‘입력 모니터링’도 필요하고 마이크 녹음에는 macOS 15 이상이 필요합니다. 앱은 Apple 공증을 받지 않았습니다. 실행이 차단되면 ‘시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기’를 사용하세요. Windows 패키지에는 Authenticode 서명이 없어 SmartScreen 경고가 표시될 수 있습니다.

Linux: Wayland 캡처는 연결된 모니터 한 대를 지원합니다. MP4 녹화에는 로컬 PulseAudio 또는 PipeWire 오디오 서비스를 통해 시스템 소리와 마이크를 포함할 수 있습니다. 클릭 강조는 아직 지원하지 않습니다. 저장한 동영상의 기본 자르기와 MP4 내보내기는 지원하지만 고급 동영상 효과는 사용할 수 없습니다. 설정과 녹화 제어는 [Linux 안내](linux.md)를 참고하세요.

업데이트: macOS와 Windows 설치 버전은 ‘설정 → 정보 → 업데이트 확인’을 사용합니다. Linux와 Windows Portable 사용자는 Releases에서 새 패키지를 다운로드하세요. Portable 설정과 캡처 자료는 Windows 사용자 프로필에 보관됩니다.

macOS Dock: ‘설정 → Dock에 표시’는 Dock 아이콘을 즉시 바꾸고 선택을 기억합니다. 아이콘을 숨겨도 트레이와 캡처 단축키는 계속 사용할 수 있습니다.

## 언어

‘설정 → 일반 → 언어’에서 English, 简体中文, 繁體中文, 日本語, Deutsch, 한국어, Français를 선택하세요. 선택은 모든 Kiri 창에 즉시 적용되며 다시 시작해도 유지됩니다. 처음에는 시스템 언어를 따릅니다. 인터페이스 언어를 바꿔도 Linux에 설치된 OCR 언어 데이터는 바뀌지 않습니다.

## 캡처

macOS에서 ⇧⌘A, Windows / Linux X11에서 Shift+Ctrl+A를 누른 뒤 창을 선택하거나 영역을 드래그합니다. Wayland에서는 캡처 버튼을 사용하거나 데스크톱 설정에서 `kiri --capture`에 단축키를 지정하세요. 지원하는 데스크톱은 ‘설정 → 단축키 → Wayland 데스크톱 단축키’에서 캡처, 일시 정지/재개, 중지 권한을 승인할 수 있습니다. Ubuntu 24.04 / GNOME 46에서는 명령 방식도 유지됩니다.

macOS, Windows, Linux에서 Kiri 실행 파일에 `--capture`, `--record`, `--ocr`, `--library`를 전달하면 각각 스크린샷 영역 선택, 녹화 영역 선택, 텍스트 인식, 기본 창을 열 수 있으며, Kiri 실행 여부와 관계없이 사용할 수 있습니다.

스크린샷, 녹화 또는 OCR을 선택합니다. 스크린샷 도구 모음에서는 QR 코드도 인식할 수 있습니다. Enter로 스크린샷을 완료하고 Esc로 캡처를 취소합니다. 스크린샷은 클립보드와 로컬 라이브러리에 저장됩니다. macOS, Windows, X11에서는 설정 → 단축키의 입력란을 클릭한 뒤 사용할 키를 눌러 지정하고, 해제하거나 기본값으로 복원할 수 있습니다. 녹화 제어 단축키는 녹화 중에만 작동합니다.

주석 도구를 고르기 전에 스크린샷 도구 모음의 슬라이더 버튼을 누르면 선택 영역 가장자리에 편집할 수 있는 너비와 높이가 나타납니다. Retina에서도 값은 출력 픽셀 기준입니다. Enter를 누르거나 입력란을 벗어나면 적용됩니다. Esc는 현재 입력을 버리고, 다시 누르면 캡처를 취소합니다. 방향키는 1픽셀, Shift와 함께 누르면 10픽셀씩 조절합니다. 슬라이더를 다시 누르면 값을 숨깁니다. 주석을 시작한 뒤에는 외관 설정에 사용됩니다.

macOS에서 영역 선택 후 모니터 배치, 해상도 또는 배율을 변경했다면 녹화 전에 다시 캡처하세요. 녹화가 일시 정지된 상태라면 먼저 중지하고 저장하세요.

주석 텍스트를 입력할 때 Ctrl/Cmd+Z는 텍스트를 실행 취소하며 Shift+Enter는 줄을 추가합니다. Esc는 먼저 텍스트 편집을 끝내고, 다시 누르면 캡처를 취소합니다. 저장된 이미지를 편집한 뒤 닫을 때 저장하지 않은 변경 사항이 있으면 저장, 버리기 또는 계속 편집을 선택할 수 있습니다.

GNOME Wayland에서 첫 캡처에 권한 대화 상자가 나타나지 않으면 라이브러리를 열고 오류 배너에서 접근 권한을 요청하세요. GNOME 대화 상자에서 스크린샷을 허용한 뒤 다시 캡처합니다. Kiri는 권한 승인에 사용한 이미지를 버립니다. [Linux 안내](linux.md)를 참고하세요.

녹화 준비 패널에는 MP4 / GIF, 시작 버튼과 시스템 소리, 마이크, 마우스 포인터, 클릭 강조 아이콘 네 개가 나란히 표시됩니다. 시작하면 항상 3초 카운트다운을 거치며 GIF는 소리 없이 녹화합니다. 패널은 선택 영역과 화면 가장자리에 맞춰 배치됩니다.

마이크 옆의 작은 화살표에서 실제 입력 장치를 선택할 수 있으며 시스템 기본 장치는 바뀌지 않습니다. 선택한 장치를 사용할 수 없거나 연결이 끊어지면 오류를 표시하고 다른 마이크로 자동 전환하지 않습니다.

### 녹화 중 주석 추가

macOS와 Windows에서는 녹화 컨트롤의 **녹화에 주석 추가**를 선택해 펜, 화살표, 사각형, 텍스트를 추가하거나 기존 주석을 선택해 편집할 수 있습니다. 색상, 선 굵기, 글자 크기는 주석 설정을 따릅니다. **데스크톱 조작**을 선택하면 주석을 표시한 채 아래 앱을 다시 조작할 수 있습니다.

실행 취소와 다시 실행은 주석에 적용됩니다. **주석 지우기**는 현재 주석을 한 번에 지우며 실행 취소할 수 있습니다. 주석 레이어에 포커스가 있을 때는 Cmd/Ctrl+Shift+Backspace로도 지울 수 있습니다. Esc는 먼저 현재 텍스트 편집이나 그리기 동작을 취소하고, 다시 누르면 데스크톱 조작으로 돌아갑니다. 일시 정지 중에도 주석을 정리할 수 있으며 녹화를 재개하면 수정 결과가 반영됩니다. 실시간 주석은 녹화 화면의 일부가 되므로 나중에 동영상 편집기의 주석처럼 따로 제거할 수 없습니다. 컨트롤, 선택 테두리, 텍스트 커서는 녹화되지 않습니다. Linux에서는 녹화 중 주석을 지원하지 않습니다.

## 스크롤 캡처

스크롤 캡처를 저장한 뒤 완료 미리보기의 이미지를 클릭하면 편집기에서 주석을 추가할 수 있습니다. 라이브러리에서도 열 수 있습니다.

스크롤할 내용을 선택한 뒤 주석을 추가하기 전에 스크린샷 도구 모음에서 **스크롤 캡처**를 선택하세요. 어느 위치에서든 시작해 평소처럼 위아래로 스크롤할 수 있습니다. 이미 캡처한 곳으로 돌아가도 내용이 중복되지 않습니다. 읽으려고 멈춰도 캡처가 끝나지 않습니다. **완료**를 누르면 복사하고 저장합니다. 저장을 시작하기 전에는 Esc로 취소할 수 있으며, Enter는 원래 앱에서 그대로 사용할 수 있습니다.

**고정**을 누르면 한 번에 캡처를 끝내고 이미지를 복사·저장한 뒤 다른 창 위에 엽니다. 참고 이미지를 열지 못해도 저장한 이미지는 남으며 완료 미리 보기에서 다시 고정할 수 있습니다. **캡처한 영역 저장**만 가능한 경우에는 먼저 해당 부분 결과를 저장한 뒤 완료 미리 보기에서 고정하세요.

스크롤 캡처 중에는 `kiri --finish-scroll-capture`로 **완료**와 같은 전체 저장 검사를 실행할 수 있으며, 부분 결과 저장으로 자동 전환하지 않습니다. `kiri --cancel-scroll-capture`는 저장이 시작되기 전에 취소합니다. 두 명령은 현재 세션만 제어하며 새 캡처를 시작하지 않습니다.

캡처하는 동안 선택 영역이 계속 표시되고 바깥쪽은 어두워집니다. 클릭, 마우스 휠, 트랙패드 제스처는 원래 앱에 그대로 전달됩니다. 이 표시는 선택 영역을 바꾸지 않으며 저장된 이미지에도 들어가지 않습니다.

미리 보기는 원본 캡처의 현재 부분을 패널 너비에 맞춰 보여 줍니다. 스크린샷이 길어져도 표시 배율은 그대로입니다. 미리 보기 안에서 위아래로 스크롤해 확인하고 포인터를 밖으로 옮기면 원래 창을 다시 따라갑니다. 제목 줄을 드래그하면 패널을 옮길 수 있으며, 작은 컨트롤에서는 상태 문구를 드래그하세요. 패널은 캡처 중인 화면 안에 머물고 X11에서는 선택 영역을 피합니다.

스크롤 후 Kiri는 감지한 고정 머리글과 바닥글을 제거합니다. 다시 지나지 않은 바깥쪽 가장자리에는 그림자가 남을 수 있습니다. 복구 안내가 나타나면 해당 영역을 다시 스크롤한 뒤 전체 이미지를 저장하세요.

화면을 연결할 수 없으면 연결된 결과를 보존하고 캡처한 내용으로 돌아가도록 안내합니다. 돌아간 뒤 빠진 영역을 지나면 계속할 수 있습니다. 스크롤 막대로 건너뛰어 표시되지 않은 내용은 다시 보여야 캡처됩니다. **캡처한 영역 저장**은 현재의 부분 결과만 저장하며 누락되거나 불확실한 내용을 채우지는 않습니다. 저장에 실패해도 결과를 유지한 채 다시 시도할 수 있습니다.

macOS, Windows, Linux X11에서 지원하며 Wayland에서는 사용할 수 없습니다. macOS에서는 하나의 일반 앱 창 안에 완전히 들어가는 영역을 선택하세요. 캡처는 해당 창에 고정되며 외부의 떠 있는 창과 같은 앱의 다른 창을 제외합니다. 원래 창을 이동하거나 크기를 바꾸거나 사용할 수 없게 되면 진행 상황을 보존하고 캡처를 중단합니다. Windows와 X11은 계속 화면 영역을 캡처하므로 외부의 떠 있는 창을 자동으로 제외하지 않습니다. 해당 창을 선택 영역 밖으로 옮기세요.

넓은 빈 영역, 반복 무늬, 가로 스크롤, 확대/축소와 레이아웃 변경은 위치 추적을 중단시킬 수 있습니다. X11에서는 선택 영역 밖에 220 × 76 컨트롤과 약간의 여백이 필요합니다. macOS와 Windows는 필요한 경우 캡처에서 제외되는 컨트롤을 선택 영역 안에 배치합니다. 이미지 크기 한도에 도달하면 캡처한 영역을 저장하고 새로 시작하세요.

## 스크린샷 주석

저장된 이미지도 캡처와 같은 주석 도구를 사용합니다. 도구나 기존 주석을 선택하면 해당 옵션이 나타나고, 선택이 없으면 이미지 공간을 비워 둡니다. 긴 이미지는 창 너비에 맞춰 열리며, 폭이 좁은 이미지는 자동으로 확대되지 않습니다. 스크롤로 둘러보고 하단에서 확대/축소, 너비 맞춤, 전체 보기, 실제 크기를 선택하세요. 핀치 또는 Ctrl/Command를 누른 채 스크롤하면 확대/축소하고, 스페이스를 누른 채 드래그하면 이동합니다. 보기 배율은 저장 이미지 크기를 바꾸지 않습니다.

기존 주석을 선택하면 스타일을 변경할 수 있습니다. 모자이크는 자유 그리기, 사각형, 타원을 지원하며 픽셀 또는 흐림 효과와 강도를 조절할 수 있습니다. 워터마크(W)를 선택해 이미지에 직접 입력하고 타일 형태 워터마크의 불투명도, 각도, 간격을 조절하세요. 저장한 뒤에도 다시 편집할 수 있습니다.

글자(T), 번호 주석(N), 라벨 말풍선(B)은 스크린샷과 이미지 편집기의 도구 모음에 각각 독립된 버튼이 있습니다. 번호 주석을 선택하고 클릭해 배치한 뒤 이미지에서 설명을 직접 입력하세요. Return으로 줄을 바꾸고, 번호와 투명한 설명 상자를 따로 이동하며 크기, 색상, 채움 또는 윤곽 스타일을 조절할 수 있습니다.

기존 텍스트, 번호 주석, 라벨과 워터마크는 클릭하여 선택하고, 드래그하여 이동하며, 두 번 클릭하여 편집합니다. 선택한 주석은 `Delete` 또는 `Backspace` 키나 **주석 삭제**로 삭제하고 `⌘Z` / `Ctrl+Z`로 실행 취소할 수 있습니다. 텍스트 입력 중에는 글자만 삭제됩니다.

글자, 번호 설명 또는 라벨을 입력할 때 빈 곳에서 처음 조작하면 입력과 선택을 끝내고, 다음 조작에서 현재 도구를 사용합니다. 글자나 도형 도구로 기존 주석을 선택한 경우에도 먼저 빈 곳에서 선택을 해제한 뒤 새 주석을 만듭니다. 도구는 계속 선택되며 펜과 모자이크는 연속으로 그릴 수 있습니다. 워터마크 입력 중 캔버스를 클릭하면 입력을 끝내고, 다시 편집할 때 같은 워터마크를 사용합니다.

주석은 추가한 순서대로 쌓입니다. 나중에 그린 모자이크는 앞서 만든 글자, 도형, 워터마크에 적용되고 그 뒤에 추가한 주석은 위에 표시됩니다. 이동하거나 편집해도 순서는 유지됩니다.

## 참고 이미지와 색상

스크린샷 선택 영역의 빈 곳을 두 번 클릭해도 완료할 수 있습니다. 기존 텍스트는 두 번 클릭하여 편집합니다. 도구 모음의 핀으로 저장하고 고정하거나 완료 카드의 고정을 사용할 수 있습니다. 이미지를 드래그하여 창을 이동하고 오른쪽 아래 모서리로 창 크기를 비율에 맞춰 조절하세요. 마우스를 올리거나 키보드로 포커스하면 고정 해제와 닫기가 나타납니다.

긴 참고 이미지는 읽기 편한 너비로 맨 위부터 열리며, 나머지는 스크롤하여 볼 수 있습니다. 마우스 휠과 트랙패드 스크롤은 이미지를 둘러보는 데 사용합니다. 핀치하거나 Ctrl/Command를 누른 채 스크롤하면 창 크기를 바꾸지 않고 포인터 위치를 중심으로 확대/축소합니다. 스페이스를 누른 채 드래그하거나 마우스 가운데 버튼으로 드래그하면 이미지 안을 이동하며, 일반 드래그는 계속 창을 움직입니다. 마우스를 올리거나 키보드로 포커스하면 배율 조절이 나타나며, 배율 메뉴에서 **너비 맞춤**, **전체 보기**, **실제 크기**를 선택할 수 있습니다. Ctrl/Command +/−는 확대/축소, Ctrl/Command+0은 전체 보기, Ctrl/Command+1은 원래 픽셀 밀도로 복원합니다. Esc 또는 Ctrl/Command+W로 참고 이미지를 닫습니다. 보기 조작은 저장한 이미지를 바꾸지 않습니다.

스크린샷 모드에서 마우스를 올리면 원본 픽셀, 좌표 및 HEX 색상 값을 확대해 볼 수 있습니다. macOS에서는 `⌘C`, 다른 환경에서는 `Ctrl+C`로 색상을 복사하며 선택 영역은 유지됩니다. 주석을 시작하면 돋보기가 숨겨집니다.

## GIF 변환

라이브러리에 저장한 MP4를 GIF로 변환할 때 Kiri는 먼저 동영상 디코딩을 확인한 뒤 GIF 인코딩을 시작합니다. 확인과 변환 중에 취소할 수 있으며 여러 작업은 한꺼번에 취소할 수 있습니다. 원본 동영상은 유지됩니다. 마지막 라이브러리 저장 단계가 시작된 뒤에는 취소할 수 없습니다.

## 라이브러리와 의견 보내기

여러 항목 선택에서 개별 항목 또는 전체를 선택하여 휴지통으로 옮길 수 있으며, 일반 클릭은 항목을 엽니다. 휴지통은 일괄 복원을 지원하고 비우기 전에 주 창에서 확인합니다. 이름 변경은 파일 형식을 유지하면서 실제 파일명도 바꿉니다. 우클릭 메뉴의 파일 복사는 폴더에 붙여넣을 때 쓰고, 일반 복사는 이미지를 붙여넣습니다.

문제를 신고할 때 설정 → 정보에서 앱, 시스템, 화면 정보를 복사할 수 있습니다. 캡처, 인증 정보, 개인 경로는 포함되지 않습니다.

설정의 앱 정보에서 설정·로그 폴더와 GitHub를 열 수 있습니다. Windows에서는 오류 로그와 시스템 임시 폴더도 열 수 있습니다. 이 작업은 파일을 삭제하지 않습니다.
