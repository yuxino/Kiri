# Kiri で動画を編集する

[简体中文](video-editing.zh-CN.md) · [English](video-editing.md) · [繁體中文](video-editing.zh-TW.md) · **日本語** · [Deutsch](video-editing.de.md) · [한국어](video-editing.ko.md) · [Français](video-editing.fr.md)

ライブラリで動画を開き、画面上部の「トリミングと書き出し」を選びます。このガイドは現在のソースに対応しています。インストール済みバージョンの操作は更新履歴をご確認ください。

**Linux：**通常速度のカット、クリップの削除・並べ替え、出力サイズのプリセット、元の音声を含む別の MP4 への書き出しに対応します。以下の速度変更、注釈、ステッカー、効果は macOS / Windows のみです。未対応の操作を含む保存プロジェクトは変更せず、読み取り専用で保持します。入力はプログレッシブ方式・正方形ピクセルの動画トラック一つと、最大一つの音声トラックで、字幕は含めません。必要なコーデックのインストールも必要です。

一つのプロジェクトは一つの元動画を編集します。分割や並べ替えはできますが、複数の動画を一つのタイムラインに結合することはできません。

## 録画やローカルファイルを読み込む

Kiri の録画はライブラリに表示されます。他のファイルは「メディアを読み込む」を選ぶか、PNG、JPEG、WebP、MP4、MOV をライブラリにドラッグします。画像は画像エディター、動画は動画エディターで開きます。

読み込みは元のファイル名を保持し、フィルターを解除するとライブラリの先頭に表示されます。画像は向きを適用して PNG に変換し、動画はコピーします。元ファイルは変更しません。一回に最大 32 ファイル。画像はデコーダーのメモリ上限に収まり、32 MB 以下、各辺 8192 ピクセル以下である必要があります。動画は 8 GB 以下です。

## クリップを切り取り、調整する

- タイムラインをクリックして移動します。端をドラッグしてトリミングし、再生位置で分割、不要なクリップを削除、ドラッグで並べ替えできます。
- クリップを選ぶと 0.25〜4 倍の速度を設定でき、プレビューと書き出しの両方に反映されます。
- タイムラインの高さを調整できます。追加トラックは内部でスクロールし、動画表示の空間を残します。
- カット、順序、速度、効果、注釈、時間設定は元に戻す・やり直す操作に対応します。削除は選択中のクリップ、注釈、ステッカー、効果に適用します。

再生操作は画像の外にあります。シークバーはキーボード操作とホバー時の時刻表示に対応します。ドラッグ中は一時停止し、離すと元の再生状態に戻ります。プリセットと 0.1〜8 倍のカスタム再生速度は閲覧用として記憶し、書き出し速度は変えません。

## 注釈、ステッカー、効果を追加する

ペン、四角形、線、矢印、編集可能な文字、ピクセル・ぼかしモザイクなどの撮影ツールを使えます。保存した外観設定を使い、初期の色は赤です。動画のモザイクは自由な線、四角形、楕円で追加できます。

描いた注釈は選択されます。属性パネルで色、太さ、モザイク設定を変え、ハンドルをドラッグして形を調整します。「文字を編集」で内容を変更し、文字サイズ、色、背景はすぐに反映されます。文字トラックは内容を表示します。Esc は現在の文字編集をキャンセルします。

ツールバーから静止 PNG、JPEG、WebP のステッカーを追加できます。透明部分を保ち、比率を変えずに拡大縮小します。注釈、ステッカー、マスクは画像上で選択して移動できます。

効果は時間指定の 1.5〜4 倍ズームと開始・終了の調整、ぼかし・ピクセルマスク、指定色の塗りつぶしマスクです。ズーム後の画像をドラッグして構図を調整できます。スポットライト、比率を保った切り抜きと背景・余白、長さと色を選べるフェードイン・アウトもあります。使用頻度の低い設定は仕上げの項目にあります。変更はすぐに画面に表示されます。

各注釈、ステッカー、効果は独立した表示時間を持ちます。トラック中央をドラッグして時間移動、端で長さ変更、左のハンドルを上下に動かしてレイヤー順を変更します。端に近づくとリストがスクロールします。上の重ね合わせは下を覆い、プレビューと書き出しで一致します。画像全体の調整は別の順序付きグループです。時間表示はカットと速度変更後の完成動画のタイムラインに従います。

## 保存して後から続ける

編集、時間付きレイヤー、ステッカー、現在位置はローカルライブラリに自動保存します。元動画を開き直して続けるか、Cmd/Ctrl+S ですぐに保存できます。閉じる際は文字編集を確定して保存を待ちます。失敗時は再試行か編集の継続を選べます。保存せず閉じる選択をした場合も、最後に成功したプロジェクトは残ります。

編集プロジェクトと書き出した MP4 は別です。書き出しは元動画を置き換えません。

## MP4 を書き出す

右上の「書き出し」を選びます。画質メニューは実際の出力サイズを表示します。

| 設定 | 出力サイズ |
| --- | --- |
| 高画質 | 元のサイズを保持 |
| 共有向け | 最長辺 1080 ピクセルまで |
| コンパクト | 最長辺 720 ピクセルまで |

小さい元動画は拡大しません。ファイルサイズは元動画と編集後の長さに依存します。新しいコピーをライブラリに作成し、エンコード進捗を表示します。最後のライブラリ保存前ならキャンセルできます。キャンセルはプロジェクトを残し、未完成の動画を追加しません。

音声は同期を保ちます。Linux は音声を 48 kHz ステレオ AAC に変換し、動画の向きを適用し、可変フレームレートと長く保持されたフレームの表示時間を保ちます。macOS は速度変更時に音程を保ち、Windows は速度に合わせて音程も変わります。Windows の効果は現在、回転情報のない動画が必要です。Kiri の録画はこの条件を満たします。
