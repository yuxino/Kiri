## インストールと更新

[最新版をダウンロード →](https://github.com/yuxino/kiri/releases/latest)

| プラットフォーム | インストール |
| --- | --- |
| macOS 14+ · Apple シリコン / Intel | Universal `.dmg` を開き、Kiri を「アプリケーション」にドラッグします。 |
| Windows 11 · x64 | `.exe` インストーラーを実行するか、Portable ZIP を展開して `kiri.exe` を実行します。 |
| Ubuntu 24.04 · x64 · GNOME / X11 | `.deb` をダウンロードし、実際のファイル名で `sudo apt install ./kiri_VERSION_amd64.deb` を実行します。 |

macOS では「画面とシステムオーディオの収録」の許可が必要です。クリック表示には「入力監視」も必要で、マイク録音には macOS 15+ が必要です。Apple の公証は受けていません。起動がブロックされた場合は「システム設定 → プライバシーとセキュリティ → このまま開く」を使ってください。Windows パッケージは Authenticode 署名がないため、SmartScreen が警告する場合があります。

Linux：Wayland の撮影は接続されたディスプレイ一台に対応します。MP4 録画はローカルの PulseAudio / PipeWire を通してシステム音声とマイクを含められます。クリック表示は未対応です。保存動画の基本的なカットと MP4 書き出しに対応しますが、高度な動画効果は使えません。設定と録画操作は [Linux ガイド](linux.md)をご覧ください。

更新：macOS と Windows のインストール版は「設定 → Kiri について → アップデートを確認」を使います。Linux と Windows Portable は Releases から新しいパッケージをダウンロードします。Portable の設定と撮影データは Windows のユーザープロファイルに残ります。

macOS Dock：「設定 → Dock に表示」でアイコンをすぐに切り替え、選択を記憶します。非表示でもメニューバーと撮影ショートカットは使えます。

## 言語

「設定 → 一般 → 言語」で English、简体中文、繁體中文、日本語、Deutsch、한국어、Français を選べます。選択はすべての Kiri ウィンドウに反映され、再起動後も保持されます。初回はシステム言語に従います。表示言語の変更は、Linux にインストールされた OCR 言語データを変えません。

## 撮影

macOS では ⇧⌘A、Windows / Linux X11 では Shift+Ctrl+A を押し、ウィンドウまたは範囲を選びます。Wayland は撮影ボタンを使うか、デスクトップ設定で `kiri --capture` をショートカットに割り当てます。対応するデスクトップでは「設定 → ショートカット → Wayland デスクトップショートカット」から、撮影、一時停止/再開、停止を許可できます。Ubuntu 24.04 / GNOME 46 ではコマンド方式を引き続き使えます。

macOS、Windows、Linux では、Kiri の実行ファイルに `--capture`、`--record`、`--ocr`、`--library` を渡すと、それぞれスクリーンショットの範囲選択、録画の範囲選択、文字認識、メインウィンドウを開けます。Kiri が起動中でも未起動でも使えます。

スクリーンショット、録画、OCR を選びます。撮影ツールバーでは QR コード認識も使えます。Enter で撮影を確定し、Esc でキャンセル。画像はクリップボードとローカルライブラリに保存されます。macOS、Windows、X11 では「設定 → ショートカット」のキー欄を押して直接登録でき、解除や初期設定への復元もできます。録画の操作キーは録画中のみ有効です。

注釈ツールを選ぶ前にスライダーボタンを押すと、選択範囲の端で幅と高さを編集できます。値は Retina でも出力ピクセルです。Enter または入力欄から離れると適用されます。Esc で入力を破棄し、もう一度 Esc で撮影をキャンセル。矢印キーは一ピクセル、Shift を押すと十ピクセルずつ調整します。再度スライダーを押すと数値を隠します。注釈開始後は外観設定に使います。

macOS で範囲選択後にディスプレイの配置、解像度、拡大率を変えた場合は、録画前に撮影をやり直してください。一時停止中なら、先に停止して保存します。

文字入力中は Ctrl/Cmd+Z で元に戻せます。通常のテキスト、ラベル、透かしでは Enter で現在の編集だけを確定し、Shift+Enter で改行します。番号付き注釈の説明では Enter で改行します。Ctrl/Cmd+Enter はどの文字編集でも確定に使えます。文字入力欄がなく撮影キャンバスにフォーカスがあるときは、Enter で撮影を完了します。Esc は現在の文字編集を取り消し、もう一度押すと撮影をキャンセルします。保存画像の編集を閉じる際、未保存の変更があれば保存、破棄、編集を続ける選択肢が出ます。

GNOME Wayland の初回撮影で許可ダイアログが出ない場合は、ライブラリのエラーバナーからアクセスを要求してください。GNOME のダイアログで撮影を許可してから再試行します。Kiri は許可用の画像を破棄します。[Linux ガイド](linux.md)もご覧ください。

録画の準備パネルには MP4 / GIF、開始ボタンと、システム音声・マイク・マウスポインター・クリック表示の四つのアイコンが並びます。開始すると必ず 3 秒のカウントダウンが入り、GIF は音声なしで録画します。パネルは選択範囲と画面端に合わせて配置されます。

マイク横の小さな矢印から実際の入力デバイスを選べます。システムの既定デバイスは変わりません。選んだデバイスが利用できない、または切断された場合はエラーを表示し、別のマイクへ自動で切り替えません。

## スクロール撮影

スクロールする内容を選び、注釈を追加する前にツールバーの「スクロール撮影」を選んでください。途中の位置から始め、普段どおり上下にスクロールできます。撮影済みの場所に戻っても、内容は重複しません。読むために止まっても撮影は終了しません。「完了」でコピーして保存します。保存が始まる前なら Esc で中止でき、Enter は元のアプリで使えます。

「固定」を選ぶと、撮影の完了、コピー、保存、最前面の参照画像の表示までを一度に行えます。参照画像を開けなくても保存画像は残り、完了プレビューから再試行できます。「撮影済み範囲を保存」が表示されている場合は、先にその部分的な結果を保存し、完了プレビューから固定してください。

スクロール撮影中は `kiri --finish-scroll-capture` で「完了」と同じ全体保存の確認を行えます。部分的な結果の保存へ自動的に切り替えることはありません。`kiri --cancel-scroll-capture` は保存が始まる前に中止します。どちらも現在の撮影だけを操作し、新しい撮影は開始しません。

撮影中は選択範囲が常に表示され、範囲外が暗くなります。クリック、ホイール、トラックパッドの操作はそのまま元のアプリに届きます。この表示は選択範囲を変えず、保存画像にも入りません。

プレビューは元の撮影画像の現在の部分を、小窓の幅に合わせて表示します。画像が縦に長くなっても、表示倍率は変わりません。プレビュー内を上下にスクロールして確認し、ポインターを外すと元の画面への追従が再開します。タイトル行をドラッグすると小窓を移動できます。コンパクト表示では状態の文字をドラッグします。小窓は撮影中の画面内に収まり、X11 では選択範囲を避けます。

スクロール後、Kiri は識別した固定ヘッダーとフッターを除去します。再び通過しなかった最外縁には影が残る場合があります。復元を求められたら、その場所まで戻ってから画像全体を保存してください。

画像をつなげられない場合は、つながった範囲を保持し、撮影済みの内容に戻るよう案内します。戻ってから不足する範囲を通過すると続行できます。スクロールバーで飛ばした未表示の内容は、再び表示する必要があります。「撮影済み範囲を保存」は現在の部分的な結果だけを保存し、欠落した内容や未確認の内容を補うものではありません。保存に失敗しても結果を保持して再試行できます。

macOS、Windows、Linux X11 で利用でき、Wayland は未対応です。macOS では一つの通常のアプリウインドウ内に収まる範囲を選びます。そのウインドウだけを撮影し、外部の浮動ウインドウや同じアプリの別ウインドウを除外します。元のウインドウが移動、サイズ変更、利用不可になった場合は進捗を残して撮影を停止します。Windows と X11 は引き続き画面領域を撮影するため、外部の浮動ウインドウは自動除外されません。選択範囲の外へ移動してください。

広い空白、繰り返し模様、横スクロール、拡大率やレイアウトの変更で位置を追跡できなくなる場合があります。X11 では選択範囲外に 220 × 76 の操作パネルと少しの余白が必要です。macOS と Windows は必要に応じて撮影から除外されるパネルを範囲内に置きます。画像サイズの上限に達したら、撮影済み範囲を保存して次の撮影を始めてください。

## スクリーンショットの注釈

保存画像も撮影時と同じ注釈操作です。ツールや既存の注釈を選ぶと設定が表示され、未選択時は画像を広く表示します。縦長画像はウィンドウ幅に合わせて開きます。幅の狭い画像は自動で拡大しません。スクロールで閲覧し、下部で拡大縮小、幅／全体に合わせる、原寸表示を選べます。ピンチまたは Ctrl/Command を押しながらスクロールで拡大縮小、スペースを押しながらドラッグで移動できます。表示倍率は保存画像のサイズに影響しません。

既存の注釈を選択すると、そのスタイルを変更できます。モザイクにはフリーハンド、長方形、楕円があり、ピクセル化またはぼかしと強さを選べます。透かし（W）は画像上で直接入力でき、タイル状の透かしの不透明度、角度、間隔を調整できます。保存後も編集できます。

撮影時の設定パネルはメインツールバーの近くに表示され、注釈の選択位置には追従しません。小さなハンドルをドラッグすると、ツールバーと設定パネルを個別に動かせます。ハンドルにフォーカスがあるときは矢印キーで 2 ピクセル、Shift と同時なら 10 ピクセル移動します。手動の位置は範囲やツールを変えても今回の撮影中は保持され、次の撮影で自動配置に戻ります。設定パネルはメインツールバーと画面端を避けます。設定を閉じた場合は、ツールバーから開き直すまで閉じたままです。

テキスト（T）、番号付き注釈（N）、ラベル吹き出し（B）は、撮影画面と画像エディターのツールバーにそれぞれ独立したボタンがあります。番号付き注釈を選んでクリックし、画像上で説明を直接入力します。Return で改行でき、番号と透明な説明枠を別々に移動し、サイズ、色、塗りつぶし／輪郭を調整できます。

既存のテキスト、番号付き注釈、ラベル、透かしはクリックで選択、ドラッグで移動、ダブルクリックで編集できます。選択した注釈は `Delete` または `Backspace` キー、または「注釈を削除」で削除し、`⌘Z` / `Ctrl+Z` で元に戻せます。入力中は削除キーで文字だけを削除します。

長方形、線、矢印は空白をドラッグすると次の図形をすぐに描けます。空白のクリックだけなら選択を解除します。テキスト、番号付き注釈、ラベルは既存の注釈の選択を解除してから次を配置します。文字編集中の最初の空白操作は編集の確定と選択解除だけを行い、次の操作で注釈を配置します。IME の候補確定は通常どおり扱います。ペンとモザイクは続けて描けます。キャンバスのクリックで透かしの入力を終え、再編集では同じ透かしを使います。

撮影キャンバスを右クリックすると、文字編集中なら文字を確定し、ドラッグ中なら未完了の操作を取り消します。それ以外はオブジェクトの選択を解除して選択ツールに戻ります。確定済みの注釈、撮影範囲、元に戻す履歴は保持されます。注釈を始める前は、右クリックで範囲を解除し、もう一度右クリックすると撮影を終了します。入力欄の右クリックは通常の編集メニューのままです。

注釈は追加順に重なります。後から描いたモザイクは先の文字、図形、透かしにも適用され、その後に追加した注釈は上に表示されます。移動や編集で重なり順は変わりません。

## 参照画像と色の取得

選択範囲の何もない場所をダブルクリックしても撮影を完了できます。既存の文字のダブルクリックは編集のままです。ツールバーのピンで保存と最前面への固定ができ、完了カードの「固定」も使えます。画像をドラッグしてウインドウを移動し、右下隅で縦横比を保ってウインドウの大きさを調整できます。マウスを重ねるか操作にフォーカスすると固定解除と閉じるボタンが表示されます。

縦長の参照画像は、読みやすい幅で先頭から開き、続きはスクロールして閲覧できます。ホイールやトラックパッドのスクロールは閲覧に使います。ピンチまたは Ctrl/Command を押しながらスクロールすると、ウインドウの大きさを変えずにポインター位置を中心に拡大縮小します。スペースを押しながらのドラッグや中ボタンドラッグは画像内の移動、通常のドラッグはウインドウの移動です。マウスを重ねるかキーボードでフォーカスすると倍率操作が現れ、倍率メニューから「幅に合わせる」「全体を表示」「実際のサイズ」を選べます。Ctrl/Command +/− で拡大縮小、Ctrl/Command+0 で全体表示、Ctrl/Command+1 で元のピクセル密度に戻り、Esc または Ctrl/Command+W で閉じます。表示の変更は保存画像に影響しません。

スクリーンショットモードでは、マウスを重ねると元のピクセル、座標、HEX 色値を拡大表示します。macOS は `⌘C`、ほかの環境は `Ctrl+C` で色をコピーできます。選択範囲は保持され、注釈を始めると拡大鏡は非表示になります。

## GIF 変換

ライブラリの MP4 を GIF に変換するときは、先に動画をデコードできるか確認します。確認中や変換中はキャンセルでき、複数の処理はまとめてキャンセルできます。元の動画は残ります。最後のライブラリ保存が始まった後はキャンセルできません。

## ライブラリとフィードバック

複数選択で項目を個別またはすべて選び、ゴミ箱に移せます。通常のクリックは項目を開きます。ゴミ箱はまとめて復元でき、空にする前にメインウィンドウ内で確認します。名前の変更は形式を保ちながら実際のファイル名にも反映されます。右クリックの「ファイルをコピー」はフォルダーへの貼り付け用で、通常のコピーは画像を貼り付けます。

問題を報告する際は「設定 → このアプリについて」からアプリ、システム、ディスプレイの情報をコピーできます。画像、認証情報、個人のパスは含みません。

設定のアプリ情報には、設定・ログフォルダを開くボタンと GitHub リンクもあります。Windows ではエラーログとシステムの一時フォルダも開けます。ファイルは削除されません。

## プライバシー

撮影データとメディア処理はローカルに保たれます。リモート OCR は任意で、アップロード前に毎回確認します。編集可能な画像は元の画像もローカルに保持するため、注釈で覆った部分のピクセルも残ります。[プライバシーポリシー](privacy/en.md)をご覧ください。
