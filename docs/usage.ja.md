## インストールと更新

[最新版をダウンロード →](https://github.com/yuxino/kiri/releases/latest)

| プラットフォーム | インストール |
| --- | --- |
| macOS 14+ · Apple シリコン / Intel | Universal `.dmg` を開き、Kiri を「アプリケーション」にドラッグします。 |
| Windows 11 · x64 | `.exe` インストーラーを実行するか、Portable ZIP を展開して `kiri.exe` を実行します。 |
| Ubuntu 24.04 · x64 · GNOME / X11 | `.deb` をダウンロードし、実際のファイル名で `sudo apt install ./kiri_VERSION_amd64.deb` を実行します。 |

macOS では「画面とシステムオーディオの収録」の許可が必要です。クリック表示には「入力監視」も必要で、マイク録音には macOS 15+ が必要です。Apple の公証は受けていません。起動がブロックされた場合は「システム設定 → プライバシーとセキュリティ → このまま開く」を使ってください。Windows パッケージは Authenticode 署名がないため、SmartScreen が警告する場合があります。

Linux：Wayland の撮影は接続されたディスプレイ一台に対応します。MP4 録画はローカルの PulseAudio / PipeWire を通してシステム音声とマイクを含められます。クリック表示は未対応です。保存動画の基本的なカットと MP4 書き出しに対応しますが、高度な動画効果は使えません。設定と録画操作は [Linux ガイド](linux.md)をご覧ください。

更新：macOS と Windows のインストール版は「設定 → Kiri について → アップデートを確認」を使います。Linux と Windows Portable は Releases から新しいパッケージをダウンロードします。Portable の設定と撮影データは Windows のユーザープロファイルに残ります。

macOS Dock：「設定 → Dock に表示」でアイコンをすぐに切り替え、選択を記憶します。非表示でもメニューバーと撮影ショートカットは使えます。

## 言語

「設定 → 一般 → 言語」で English、简体中文、繁體中文、日本語、Deutsch、한국어、Français を選べます。選択はすべての Kiri ウィンドウに反映され、再起動後も保持されます。初回はシステム言語に従います。表示言語の変更は、Linux にインストールされた OCR 言語データを変えません。

## 撮影

macOS では ⇧⌘A、Windows / Linux X11 では Shift+Ctrl+A を押し、ウィンドウまたは範囲を選びます。Wayland は撮影ボタンを使うか、デスクトップ設定で `kiri --capture` をショートカットに割り当てます。対応するデスクトップでは「設定 → 一般 → Wayland デスクトップショートカット」から、撮影、一時停止/再開、停止を許可できます。Ubuntu 24.04 / GNOME 46 ではコマンド方式を引き続き使えます。

スクリーンショット、録画、OCR を選びます。撮影ツールバーでは QR コード認識も使えます。Enter で撮影を確定し、Esc でキャンセル。画像はクリップボードとローカルライブラリに保存されます。macOS、Windows、X11 の撮影ショートカットは設定で変更できます。

注釈ツールを選ぶ前にスライダーボタンを押すと、選択範囲の端で幅と高さを編集できます。値は Retina でも出力ピクセルです。Enter または入力欄から離れると適用されます。Esc で入力を破棄し、もう一度 Esc で撮影をキャンセル。矢印キーは一ピクセル、Shift を押すと十ピクセルずつ調整します。再度スライダーを押すと数値を隠します。注釈開始後は外観設定に使います。

macOS で範囲選択後にディスプレイの配置、解像度、拡大率を変えた場合は、録画前に撮影をやり直してください。一時停止中なら、先に停止して保存します。

注釈の文字入力中は Ctrl/Cmd+Z で文字を元に戻し、Shift+Enter で改行します。Esc は先に文字編集を終了し、もう一度押すと撮影をキャンセルします。保存画像の編集を閉じる際、未保存の変更があれば保存、破棄、編集を続ける選択肢が出ます。

GNOME Wayland の初回撮影で許可ダイアログが出ない場合は、ライブラリのエラーバナーからアクセスを要求してください。GNOME のダイアログで撮影を許可してから再試行します。Kiri は許可用の画像を破棄します。[Linux ガイド](linux.md)もご覧ください。

録画の準備パネルには MP4 / GIF、開始ボタンと、システム音声・マイク・マウスポインター・クリック表示の四つのアイコンが並びます。開始すると必ず 3 秒のカウントダウンが入り、GIF は音声なしで録画します。パネルは選択範囲と画面端に合わせて配置されます。

マイク横の小さな矢印から実際の入力デバイスを選べます。システムの既定デバイスは変わりません。選んだデバイスが利用できない、または切断された場合はエラーを表示し、別のマイクへ自動で切り替えません。

## スクリーンショットの注釈

既存の注釈を選択すると、そのスタイルを変更できます。モザイクにはフリーハンド、長方形、楕円があり、ピクセル化またはぼかしと強さを選べます。透かし（W）は画像上で直接入力でき、単独またはタイル表示、不透明度、角度、間隔を調整できます。保存後も編集できます。

テキスト（T）、番号付き注釈（N）、ラベル吹き出し（B）は、撮影画面と画像エディターのツールバーにそれぞれ独立したボタンがあります。番号付き注釈を選んでクリックし、画像上で説明を直接入力します。Return で改行でき、番号と透明な説明枠を別々に移動し、サイズ、色、塗りつぶし／輪郭を調整できます。

既存のテキスト、番号付き注釈、ラベル、透かしはクリックで選択、ドラッグで移動、ダブルクリックで編集できます。選択した注釈は `Delete` または `Backspace` キー、または「注釈を削除」で削除し、`⌘Z` / `Ctrl+Z` で元に戻せます。入力中は削除キーで文字だけを削除します。

文字、番号付き注釈の説明、ラベルの入力中は、空白での操作でまず編集と選択を終了し、次の操作で現在のツールを使います。文字や図形のツールで既存の注釈を選択している場合も、空白でまず選択を解除し、その次に新しく配置します。ツールの選択は保持され、ペンとモザイクは続けて描けます。透かしの入力中にキャンバスをクリックすると入力を終了し、再編集では同じ透かしを使います。

注釈は追加順に重なります。後から描いたモザイクは先の文字、図形、透かしにも適用され、その後に追加した注釈は上に表示されます。移動や編集で重なり順は変わりません。

## 参照画像と色の取得

選択範囲の何もない場所をダブルクリックしても撮影を完了できます。既存の文字のダブルクリックは編集のままです。ツールバーのピンで保存と最前面への固定ができ、完了カードの「固定」も使えます。画像をドラッグして移動し、右下隅で縦横比を保って拡大縮小できます。マウスを重ねると固定解除と閉じるボタンが表示されます。

スクリーンショットモードでは、マウスを重ねると元のピクセル、座標、HEX 色値を拡大表示します。macOS は `⌘C`、ほかの環境は `Ctrl+C` で色をコピーできます。選択範囲は保持され、注釈を始めると拡大鏡は非表示になります。

## GIF 変換

ライブラリの MP4 を GIF に変換するときは、先に動画をデコードできるか確認します。確認中や変換中はキャンセルでき、複数の処理はまとめてキャンセルできます。元の動画は残ります。最後のライブラリ保存が始まった後はキャンセルできません。

## ライブラリとフィードバック

複数選択で項目を個別またはすべて選び、ゴミ箱に移せます。通常のクリックは項目を開きます。ゴミ箱はまとめて復元でき、空にする前にメインウィンドウ内で確認します。名前の変更は形式を保ちながら実際のファイル名にも反映されます。右クリックの「ファイルをコピー」はフォルダーへの貼り付け用で、通常のコピーは画像を貼り付けます。

問題を報告する際は「設定 → このアプリについて」からアプリ、システム、ディスプレイの情報をコピーできます。画像、認証情報、個人のパスは含みません。

設定のアプリ情報には、設定・ログフォルダを開くボタンと GitHub リンクもあります。Windows ではエラーログとシステムの一時フォルダも開けます。ファイルは削除されません。

## プライバシー

撮影データとメディア処理はローカルに保たれます。リモート OCR は任意で、アップロード前に毎回確認します。編集可能な画像は元の画像もローカルに保持するため、注釈で覆った部分のピクセルも残ります。[プライバシーポリシー](privacy/en.md)をご覧ください。
