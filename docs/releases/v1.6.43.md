## English

- Interrupted in-app update downloads on macOS and installed Windows builds retain their downloaded data, including after restarting Kiri. Choose **Resume Download** to continue.
- Slow downloads can keep progressing without the previous two-minute overall timeout. Completed update packages are still signature-verified before installation.
- These improvements take effect after installing v1.6.43. If an older version cannot download this update, download and install the matching package from this release page.
- Linux and portable Windows builds continue to use manual replacement packages.

## 中文

- macOS 和安装版 Windows 的应用内更新下载中断后，会保留已下载的数据；重启 Kiri 后也能点击「继续下载」接着下载。
- 移除了原来的两分钟整体下载时限，网速较慢但仍在传输时可以继续下载。完整更新包仍会在安装前验证签名。
- 这些改进在安装 v1.6.43 后生效。如果旧版本无法下载本次更新，请从此发布页下载对应安装包并手动安装。
- Linux 和 Windows 便携版继续通过手动下载并替换安装包更新。
