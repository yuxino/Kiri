## English

- Fix video previews that could not be closed after their media became unavailable. Normal editing still saves changes before closing, and an active export remains protected.
- Fix provisional scrolling-screenshot rows that could remain incorrect after returning to their original position.
- Add optional **Start at login** in Settings → General. It is off by default and starts Kiri in the background without opening the library.
- Show more specific scrolling-capture startup errors and retain the failed stage for troubleshooting on Windows.

The reported Windows scrolling-capture startup failure is still under investigation; better diagnostics do not establish that it is fixed. The full reported video-copy/deletion workflow also remains under investigation. Actual logout/login acceptance for startup remains unverified. Scrolling screenshots remain unavailable on Wayland.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download the new package](https://github.com/yuxino/kiri/releases/latest). macOS packages keep the existing signing identity and are not notarized; first-time installation may require **Open Anyway** in System Settings → Privacy & Security.

## 中文

- 修复视频文件不可用后，预览窗口无法关闭的问题。正常编辑仍会在关闭前保存，导出过程中仍保留关闭保护。
- 修复滚动长截图返回原位置后，部分待确认的图像行无法恢复的问题。
- 在「设置 → 通用」新增可选的「登录时启动」，默认关闭；开启后登录时在后台运行，不弹出素材库。
- 细分滚动截图启动失败提示，并保留失败阶段，便于排查 Windows 问题。

反馈中的 Windows 滚动截图启动失败仍在排查，诊断改进不代表已经修复；视频副本与删除操作的完整反馈链路也仍待确认。自启尚未完成退出登录再登录的验收。Wayland 仍不支持滚动截图。

macOS 和 Windows 安装版可在「设置 → 关于」更新；Linux 和 Windows 绿色版请[下载新版安装包](https://github.com/yuxino/kiri/releases/latest)。macOS 安装包沿用现有签名，未经 Apple 公证；首次安装可能需要在「系统设置 → 隐私与安全性」选择「仍要打开」。
