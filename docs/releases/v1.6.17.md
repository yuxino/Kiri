## English

- Add **Recognize Text** to the screenshot toolbar. It uses the selected region and keeps the existing confirmation before sending an image to a remote OCR service.
- Fix annotation layer order: later mosaics cover earlier text and other annotations. Later annotations remain above the mosaic, and editing, Undo/Redo and reopening preserve that order.
- Fix dragging pinned screenshots on macOS. Unpinning and pinning again keep the reference movable; saved edits also refresh an already-open reference.

Thanks to @yuxino for this release's fixes, and to @az6161311 for reporting the screenshot OCR and mosaic issues.

Update through Settings on macOS and installed Windows. Replace the ZIP for Windows Portable. On Linux, install with `sudo apt install ./kiri_1.6.17_amd64.deb`. macOS retains Kiri's stable signing identity but is not Apple-notarized; if blocked, use **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

Checked with automated annotation/OCR regressions and signed macOS reference-window interactions. Intel Mac hardware, physical mixed-DPI displays, native OS IME composition and all Linux desktop/portal configurations have not been fully tested.

## 中文

- 在截图工具栏加入**识别文字**，直接使用已选区域；发送图片到远程 OCR 服务前仍需确认。
- 修复标注图层顺序：后添加的马赛克会遮住之前的文字和其他标注，之后添加的标注仍显示在马赛克上方；编辑、撤销/重做和重新打开后保持相同顺序。
- 修复 macOS 置顶截图无法拖动的问题，取消置顶或重新置顶后仍可移动；保存编辑结果也会刷新已经打开的置顶图。

感谢 @yuxino 完成本次修复，也感谢 @az6161311 反馈截图 OCR 和马赛克问题。

macOS 和 Windows 安装版可在设置中更新；Windows 便携版请替换 ZIP。Linux 请运行 `sudo apt install ./kiri_1.6.17_amd64.deb`。macOS 保留 Kiri 的稳定签名身份，但未经 Apple 公证；如被拦截，请在**系统设置 → 隐私与安全性 → 仍要打开**中允许。Windows 安装包没有 Authenticode 签名。

已通过标注/OCR 自动回归及稳定签名的 macOS 置顶窗口交互检查；Intel Mac 真机、实体混合 DPI 显示器、原生输入法组合输入和所有 Linux 桌面/门户配置尚未完整验证。
