## English

- Keep dragged tool options visible near screen edges and preserve input fields' right-click menus.
- Draw consecutive rectangles, lines and arrows without an extra click.
- Enter in the Text and Label tools now finishes the edit without completing the screenshot. Right-clicking the canvas keeps existing annotations.
- Keep properties beside the toolbar and show their first controls when switching tools or annotations.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download v1.6.34](https://github.com/yuxino/kiri/releases/tag/v1.6.34).

Thanks @yuxino for these improvements.

## 中文

- 修复拖动后工具属性在屏幕边缘被遮挡的问题，保留输入框的右键菜单。
- 连续画矩形、线条和箭头时，无需额外点击即可开始下一笔。
- 文字和标签工具中，Enter 仅结束编辑，不再直接完成截图；右键画布时保留已有标注。
- 属性面板保持在工具栏附近，切换工具或标注时显示最上方的控件。

macOS 和 Windows 安装版可在「设置 → 关于」更新；Linux 和 Windows 绿色版请[下载 v1.6.34](https://github.com/yuxino/kiri/releases/tag/v1.6.34)。

感谢 @yuxino 完成本次改进。
