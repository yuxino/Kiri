## English

- **Scrolling screenshots:** scroll naturally up or down, check the live preview, and finish when ready. Returning to captured content does not add it twice.
- **Better image editing:** zoom and pan saved images, including long screenshots. Tool options appear when needed and no longer take space away from the image.
- **Cleaner shortcut settings:** consistent icons, compact key fields, and aligned controls make bindings easier to scan.
- Fix a capture compatibility issue on macOS 14.

Scrolling screenshots support macOS, Windows and Linux X11; Wayland is not supported. Views need to overlap—after a large jump, scroll back through any missed content. See the [usage guide](https://github.com/yuxino/kiri/blob/main/docs/usage.md#scrolling-screenshots) for platform limits.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download the new package](https://github.com/yuxino/kiri/releases/latest).

## 中文

- **滚动长截图：**照常向上或向下滚动，随时查看实时预览，截够后点击完成。返回已截内容不会重复拼接。
- **图片编辑更方便：**保存后的图片和长截图都能缩放、拖动查看。工具选项按需出现，不再挤占图片空间。
- **快捷键设置更简洁：**统一图标，缩小按键框并对齐操作，查看绑定更清楚。
- 修复 macOS 14 上的一处截图兼容性问题。

滚动截图支持 macOS、Windows 和 Linux X11，Wayland 暂不可用。前后画面需要有重叠；大幅跳转后，请滚回补上未显示的内容。平台限制见[使用说明](https://github.com/yuxino/kiri/blob/main/docs/usage.zh-CN.md#滚动截图)。

macOS 和 Windows 安装版可在「**设置 → 关于**」更新；Linux 和 Windows 绿色版请[下载新版安装包](https://github.com/yuxino/kiri/releases/latest)。
