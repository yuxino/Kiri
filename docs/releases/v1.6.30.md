## English

- Fix Linux startup failures caused by newer Leptonica libraries, including the case reported on Kali. Text recognition stays local.

Install the Linux package with `sudo apt install ./kiri_1.6.30_amd64.deb` so its required OCR components are installed automatically.

Kali startup and text recognition passed checks in an isolated environment. The reporter's VMware setup still needs confirmation.

Thanks @Hannam1VM for reporting [#187](https://github.com/yuxino/Kiri/issues/187).
