## English

- Add dedicated Shortcuts settings for screenshots, recording, text recognition, and the main window, with custom keys, clearing, and default restoration.
- Support function, media, and other keys accepted by the operating system. Typing and navigation keys ask for confirmation; failed changes preserve the previous shortcut.
- Add pause/resume and stop shortcuts that are active only while recording, and keep the recording controls from taking keyboard focus.
- Show annotation shortcuts and let the toolbar and tool options move independently. Refine settings, recording controls, and annotation panels with more compact spacing and neutral backgrounds.

Wayland shortcuts remain desktop-managed. On macOS, playback media keys require Accessibility access; ordinary shortcuts do not require Input Monitoring. Automated and isolated desktop checks do not establish physical-device acceptance on every platform.

Update through Settings → About on macOS and installed Windows. Linux users can download and install the new `.deb` package.

Thanks to @yuxino for these changes.

## 中文

- 新增独立快捷键设置，集中管理截图、录屏、文字识别和显示主窗口，支持自定义、清除及恢复默认。
- 支持操作系统可用的功能键、媒体键及其他按键。输入、导航类按键确认后即可使用；修改失败时保留原快捷键。
- 新增仅录制期间生效的暂停/继续和停止快捷键，录屏控制条不再抢走键盘焦点。
- 标注工具显示对应快捷键，工具栏和属性面板可独立拖动。调整设置、录屏和标注面板的间距与比例，统一为中性背景。

Wayland 快捷键仍由桌面管理。macOS 播放控制类媒体键需要「辅助功能」授权，普通快捷键不需要「输入监控」。自动化及隔离桌面检查不代表所有平台的实体设备验收。

macOS 和安装版 Windows 可在「设置 → 关于」中更新；Linux 用户可下载并安装新版 `.deb` 包。

感谢 @yuxino 完成本次改动。
