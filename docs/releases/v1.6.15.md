## English

- Add numbered notes with editable descriptions and directional label bubbles. Text, notes, and labels now have separate toolbar buttons, direct dragging, and inline editing. A first blank click finishes the current edit; the next starts another annotation.
- Add editable tiled watermarks and improve mosaic brush controls, sliders, and annotation-panel layout.
- Pin screenshots directly from the capture toolbar and copy color values from the hover color picker.
- Fix Windows freezing when opening confirmations, including Empty Trash.
- Open the selected library folder correctly, reveal the current file, rename the actual saved file along with its title, and add **Copy File** for pasting into folders.

Thanks to @az6161311 for the annotation and file-management suggestions and bug reports. Contributors to this release: @yuxino.

macOS and installed Windows builds use the signed, user-initiated updater. Replace the ZIP for Windows Portable. On Linux, install with `sudo apt install ./kiri_1.6.15_amd64.deb`. macOS retains Kiri's stable local signing identity and is not Apple-notarized; if blocked, approve it through **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

macOS interactions and automated Windows/Linux package checks cover the main changes. Intel Mac hardware, physical mixed-DPI displays, and every Linux desktop/portal configuration have not been fully tested.

## 中文

- 新增可编辑说明文字的序号标注和方向标签气泡。文字、序号和标签各自放在工具栏中，支持直接拖动和原位输入。第一次点击空白处结束当前编辑，再次点击才开始下一个标注。
- 新增可再次编辑的平铺水印，改进马赛克画笔、滑块和标注属性面板布局。
- 支持从截图工具栏直接置顶，并通过悬停取色器复制颜色值。
- 修复 Windows 打开确认窗口时卡死的问题，包括清空回收站。
- 正确打开所选素材库文件夹、定位当前文件；重命名同时修改标题和实际保存的文件名，并新增可粘贴到文件夹的**复制文件**。

感谢 @az6161311 提供标注、文件管理建议和问题反馈。本版本贡献者：@yuxino。

macOS 和 Windows 安装版通过签名更新器手动更新；Windows 便携版替换 ZIP。Linux 使用 `sudo apt install ./kiri_1.6.15_amd64.deb` 安装。macOS 保留 Kiri 现有的稳定本地签名，尚未经过 Apple 公证；如被阻止，请在**系统设置 → 隐私与安全性 → 仍要打开**中批准。Windows 安装包未使用 Authenticode 签名。

主要改动经过 macOS 交互验收和 Windows/Linux 安装包自动检查。Intel Mac 真机、实体混合 DPI 显示器以及全部 Linux 桌面和 Portal 配置尚未完整测试。
