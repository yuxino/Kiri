## English

- Fix Linux system-audio recording stopping immediately on buffered PulseAudio FIFO output monitors. Future audio now has its own bounded native receive queue while waiting for its video presentation time; discontinuity, overflow and device-change checks remain active. Each segment primes audio before the shared recording clock, excluding preparation time and its initial silence.
- Add a private FIFO regression with verified generated sound, system-audio-only recording, pause/resume merging and a silent control. Installed X11 acceptance also decodes AAC and checks captured frames and control exclusion.

Contributors to this release: @yuxino.

macOS and installed Windows builds use the signed, user-initiated updater. Windows Portable updates by replacing its ZIP. On Linux, install with `sudo apt install ./kiri_1.6.12_amd64.deb`; updates replace the `.deb`. macOS retains Kiri's stable local signing identity and is not Apple-notarized; if blocked, approve it through **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

Verification covers controlled native FIFO audio, a generated 60-second A/V clock check, and the installed Ubuntu 24.04 X11 app on an isolated virtual desktop with microphone off. macOS and Windows package checks are also performed. The deleted cloud desktop from #101 could not be rerun; physical audio devices, PipeWire-Pulse hardware behavior and GNOME Wayland were not accepted for this fix. See [the investigation](https://github.com/yuxino/Kiri/blob/v1.6.12/docs/qa/linux-fifo-system-audio.md).

Full changelog: [v1.6.11 → v1.6.12](https://github.com/yuxino/Kiri/compare/v1.6.11...v1.6.12).

## 中文

- 修复 Linux 在带缓冲的 PulseAudio FIFO 输出监视源上录制系统声音时立即停止的问题。等待与视频呈现时间对齐的音频现在使用单独且有上限的原生接收缓冲；时间跳变、溢出和设备变化检查仍然生效。每段录制会先准备音频，再启动共同音画时钟，避免把准备时间和开头的空白声音写入视频。
- 新增隔离 FIFO 回归验收，先确认生成的测试音实际送出，再检查仅系统声音录制、暂停恢复合并和无声对照。X11 安装版验收还会解码 AAC，检查录制画面和控件排除。

本次版本贡献者：@yuxino。

macOS 和 Windows 安装版使用用户主动触发的签名更新。Windows 绿色版通过替换 ZIP 更新。Linux 请用 `sudo apt install ./kiri_1.6.12_amd64.deb` 安装，并通过替换 `.deb` 更新。macOS 沿用 Kiri 的稳定本地签名身份，尚未经过 Apple 公证；若被拦截，可在「**系统设置 → 隐私与安全性 → 仍要打开**」中批准。Windows 包尚未使用 Authenticode 签名。

验证覆盖受控的原生 FIFO 音频、生成的 60 秒音画时钟检查，以及 Ubuntu 24.04 X11 隔离虚拟桌面上的安装版操作，麦克风保持关闭。macOS 和 Windows 安装包也会完成检查。#101 使用的云桌面已删除，无法原样重跑；本次未验收物理音频设备、PipeWire-Pulse 硬件行为和 GNOME Wayland。详见[排查记录](https://github.com/yuxino/Kiri/blob/v1.6.12/docs/qa/linux-fifo-system-audio.md)。

完整变更：[v1.6.11 → v1.6.12](https://github.com/yuxino/Kiri/compare/v1.6.11...v1.6.12)。
