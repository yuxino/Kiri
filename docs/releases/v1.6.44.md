## English

- Fixed: on Windows, **Print Screen** can now be recorded as a global shortcut in Settings → Shortcuts. Thanks to @tiger8888 for the report (#209).
- A bare Print Screen still asks for confirmation before it is saved, like other single keys.
- This fix was verified with automated tests and CI; it has not been checked on a real Windows desktop before release. If Print Screen still cannot be recorded, please comment on #209.

## 中文

- 修复：Windows 上现在可以在「设置 → 快捷键」中把 **Print Screen** 录制为全局快捷键。感谢 @tiger8888 反馈（#209）。
- 单独的 Print Screen 与其他单键一样，保存前仍会要求确认。
- 本次修复已通过自动化测试和 CI 验证，发布前尚未在真实 Windows 桌面上实测。如果仍然无法录制 Print Screen，请在 #209 留言。
