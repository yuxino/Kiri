## English

- Library search stays beside the heading when there are many tags. Click away or press Enter to save a tag edit, and click an existing tag on a capture to rename it.
- Drag a capture or a selection onto a tag to apply it. Add a tag directly from a capture card, or use Manage Tags to add or remove a tag from several captures at once.
- Move a single Text History record to Trash or recognize its source image again. To find new captures by the text in them, turn on **Search text in new screenshots** under Settings → Text Recognition. This uses local OCR.
- Remote OCR profiles accept valid HTTP and HTTPS service URLs, including self-hosted addresses on a local network. HTTP sends the API key and image without encryption.
- Added Russian to the app languages. Thanks @AlexZander85.

## 中文

- 素材库的标签再多，搜索框也固定在标题旁。编辑标签时，点击别处或按回车即可保存。点击素材卡片上的已有标签可以改名。
- 将素材拖到标签上即可打标，拖动已选素材可为本次选中的素材一起打标。可以从卡片直接添加标签，也可以通过「管理标签」批量添加或移除标签。
- 文字历史支持将单条记录移到回收站，也可以重新识别原图。在「设置 → 文字识别」开启「搜索新截图里的文字」后，Kiri 会用本地 OCR 识别新截图，方便按图中文字搜索。
- 远程 OCR 支持有效的 HTTP 和 HTTPS 服务地址，包括局域网自建服务。通过 HTTP 发送的 API Key 和图片是明文。
- 新增俄语界面。感谢 @AlexZander85。
