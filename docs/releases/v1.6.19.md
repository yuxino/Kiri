## English

- On Windows, left-click the tray icon to open Kiri and right-click to open its menu.
- Add **Copy Info** in About to copy app and system details when reporting a problem.
- Keep a thin outline around pinned screenshots so they are easier to distinguish from the desktop.
- Double-click an empty area to finish a screenshot while using any annotation tool. Existing annotations remain editable, and the saved-image editor keeps its explicit Save action.
- Improve Windows recording startup compatibility and show startup errors on the capture screen. Fix static recordings saving shorter videos than the active recording time; pauses remain excluded.

Thanks to @yuxino for the changes and @az6161311 for the feedback and follow-up reports.

Update through Settings on macOS and installed Windows. Windows Portable users can download the new ZIP; Linux users can install with `sudo apt install ./kiri_1.6.19_amd64.deb`.

macOS retains Kiri's stable signing identity and is not Apple-notarized. If blocked, use **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

## 中文

- Windows 托盘图标左键打开 Kiri 主窗口，右键打开菜单。
- 「关于」新增**复制信息**，反馈问题时可直接复制软件和系统信息。
- 置顶截图保留一圈细边框，方便与桌面上的原画面区分。
- 使用任意标注工具时，都可以双击空白处完成截图；已有标注仍可继续编辑，二次图片编辑器保持手动保存。
- 改善 Windows 录屏启动兼容性，启动失败时直接在截图所在屏幕显示提示。修复静态画面录制后视频时长偏短的问题，暂停时间仍不计入。

感谢 @yuxino 完成本次改动，也感谢 @az6161311 的建议和后续反馈。

macOS 和 Windows 安装版可在设置中更新；Windows 便携版请下载新 ZIP。Linux 请运行 `sudo apt install ./kiri_1.6.19_amd64.deb`。

macOS 保留 Kiri 的稳定签名身份，但未经 Apple 公证；如被拦截，请在**系统设置 → 隐私与安全性 → 仍要打开**中允许。Windows 安装包没有 Authenticode 签名。
