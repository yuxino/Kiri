## English

- Kiri now uses Baidu PP-OCRv6 small for local text recognition on macOS, Windows and Linux, both for screen selections and saved screenshots. The model is included and works offline. Local system recognition remains available as a fallback.
- The result panel puts the text first. You can select another region after an empty result and retry copying without losing the text. Small toolbar icons may still be recognized as characters.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download v1.6.36](https://github.com/yuxino/Kiri/releases/tag/v1.6.36). Thanks @az6161311 for the small-text examples in #193.

## 中文

- macOS、Windows 和 Linux 统一使用百度 PP-OCRv6 small 进行本地文字识别，框选区域和素材库截图都能用。模型随安装包附带，离线可用；必要时可调用本机系统识别器。
- 识别结果优先显示正文。没读出文字时可以直接重新框选，复制失败后可以保留文字再试。工具栏里的小图标仍可能被读成字符。

macOS 和 Windows 安装版可在「设置 → 关于」更新。Linux 和 Windows 绿色版请[下载 v1.6.36](https://github.com/yuxino/Kiri/releases/tag/v1.6.36)。感谢 @az6161311 在 #193 提供小字截图。
