## English

- Keep video edits, undo history and save protection when playback fails; retry without resetting the draft.
- Fix favorite toggles and library recovery after a failed move.
- Save preferences more reliably and open settings without loading unused OCR profiles.
- Fix capture retries and QR search state, and clean up temporary GIF files.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download v1.6.32](https://github.com/yuxino/kiri/releases/tag/v1.6.32). On Linux, install with `sudo apt install ./kiri_1.6.32_amd64.deb`.

macOS packages retain the stable self-signed identity and are not Apple notarized. First-time installation may require **Open Anyway** in **System Settings → Privacy & Security**.

Video error recovery is covered by component and save-queue tests; hardware decoder failure recovery and mixed-scale physical displays remain unverified. Scrolling capture remains unavailable on Wayland.

## 中文

- 视频播放失败时保留剪辑、撤销记录和保存保护，重试不会重置草稿。
- 修复收藏切换，以及素材库移动失败后的界面恢复。
- 提高偏好设置保存的可靠性，打开设置时不再加载尚未使用的 OCR 配置。
- 修复捕获重试和二维码搜索状态，清理临时 GIF 文件。

macOS 和 Windows 安装版可在「设置 → 关于」更新；Linux 和 Windows 绿色版请[下载 v1.6.32](https://github.com/yuxino/kiri/releases/tag/v1.6.32)。Linux 请使用 `sudo apt install ./kiri_1.6.32_amd64.deb` 安装。

macOS 安装包沿用稳定自签名，未经 Apple 公证；首次安装可能需要在「系统设置 → 隐私与安全性」选择「仍要打开」。

视频异常恢复已通过组件和保存队列测试；硬件解码失败恢复及实体混合缩放多屏仍待验证。Wayland 仍不支持滚动截图。
