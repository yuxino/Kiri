## English

- Click the existing sliders button before annotating a screenshot to show width and height beside the selection. Recording options offer the same control. Values follow the selection in output pixels, including Retina and fractional display scales.
- Edit either dimension directly: Enter or clicking away applies it; Escape discards the current input. Arrow keys adjust by one pixel, or ten with Shift. Compact dark labels stay within the display, clear of each other and the toolbar, with no rectangular focus frame inside the label.

Contributors to this release: @yuxino.

macOS and installed Windows builds use the signed, user-initiated updater. Windows Portable updates by replacing its ZIP. On Linux, install with `sudo apt install ./kiri_1.6.10_amd64.deb`; updates replace the `.deb`. macOS retains Kiri's stable local signing identity and is not Apple-notarized; if blocked, approve it through **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

Verification covers geometry, Retina/fractional pixel conversion, screen-edge layout, and browser input/toggle behavior. The macOS build was installed and launched with its existing signing identity. Native selection interactions, physical displays and hardware recording were not exercised in this change. Automated package checks and their provenance are separate from physical-desktop acceptance.

Full changelog: [v1.6.9 → v1.6.10](https://github.com/yuxino/kiri/compare/v1.6.9...v1.6.10).

## 中文

- 在截图标注前，点击原有滑杆按钮即可在选区边缘显示宽、高输入框；录屏选项也提供相同入口。数值随选区同步，以输出像素显示，支持 Retina 和小数缩放。
- 可直接编辑宽或高：Enter 或点击其他位置应用输入，Esc 撤销当前输入。方向键每次调整 1 像素，按住 Shift 调整 10 像素。深色小标签保持在屏幕内，避开彼此和工具栏，编辑时不再出现标签内部的白色矩形焦点框。

本次版本贡献者：@yuxino。

macOS 和 Windows 安装版使用用户主动触发的签名更新。Windows 绿色版通过替换 ZIP 更新。Linux 请用 `sudo apt install ./kiri_1.6.10_amd64.deb` 安装，并通过替换 `.deb` 更新。macOS 沿用 Kiri 的稳定本地签名身份，尚未经过 Apple 公证；若被拦截，可在「**系统设置 → 隐私与安全性 → 仍要打开**」中批准。Windows 包尚未使用 Authenticode 签名。

验证覆盖选区几何、Retina/小数缩放像素换算、屏幕边缘布局，以及浏览器中的输入和开关交互。macOS 构建已沿用原签名安装并启动。本次未实际验收原生选区交互、物理显示器和硬件录制；自动安装包检查及其来源记录与实机桌面验收分别说明。

完整变更：[v1.6.9 → v1.6.10](https://github.com/yuxino/kiri/compare/v1.6.9...v1.6.10)。
