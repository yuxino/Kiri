## English

- Select multiple Text History or QR Favorites records and move them to Trash together. You can select all search results and restore removed records from Trash.
- Both pages now share a compact layout and consistent actions. The content preview stays visible during selection; single-record removal is in More Actions.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download v1.6.37](https://github.com/yuxino/Kiri/releases/tag/v1.6.37). On first installation, macOS may require **System Settings → Privacy & Security → Open Anyway**.

## 中文

- 文字和二维码收藏支持多选、全选搜索结果，并批量移到回收站。移除的记录可以从回收站恢复。
- 两页采用统一、紧凑的布局和操作样式。多选时仍保留内容预览，单条移除操作位于「更多操作」。

macOS 和 Windows 安装版可在「设置 → 关于」更新。Linux 和 Windows 绿色版请[下载 v1.6.37](https://github.com/yuxino/Kiri/releases/tag/v1.6.37)。macOS 首次安装时可能需要在「系统设置 → 隐私与安全性」中选择「仍要打开」。
