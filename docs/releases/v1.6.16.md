## English

- Fix deleting annotations: select an object and press Delete or Backspace, or use **Delete annotation**. Deletion supports Undo and Redo.
- Single-click existing text, numbered notes, label bubbles, or watermarks to select them; double-click to edit their text. Selecting a numbered note no longer starts typing unexpectedly.
- Fix keyboard focus after using annotation controls, and prevent Delete in video annotation mode from removing a clip when no annotation is selected.

Thanks to @yuxino for this release's fixes.

## 中文

- 修复标注难以删除的问题：选中对象后按 Delete 或退格键，也可点击**删除标注**，支持撤销和重做。
- 已有文字、序号标注、标签气泡和水印统一为单击选中、双击编辑文字。选中序号标注时不会意外进入输入状态。
- 修复调整标注属性后的键盘焦点，并防止视频标注模式下未选中标注时按 Delete 误删视频片段。

感谢 @yuxino 完成本次修复。
