## English

- Fix deleting annotations: select an object and press Delete or Backspace, or use **Delete annotation**. Deletion supports Undo and Redo.
- Single-click existing text, numbered notes, label bubbles, or watermarks to select them; double-click to edit their text. Selecting a numbered note no longer starts typing unexpectedly.
- Fix keyboard focus after using annotation controls, and prevent Delete in video annotation mode from removing a clip when no annotation is selected.

Thanks to @yuxino for this release's fixes.

Update through Settings on macOS and installed Windows. Replace the ZIP for Windows Portable. On Linux, install with `sudo apt install ./kiri_1.6.16_amd64.deb`. macOS retains Kiri's stable signing identity but is not Apple-notarized; if blocked, use **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

Verified with macOS interactions and automated Windows/Linux checks. Intel Mac hardware, physical mixed-DPI displays, and all Linux desktop/portal configurations have not been fully tested.

## 中文

- 修复标注难以删除的问题：选中对象后按 Delete 或退格键，也可点击**删除标注**，支持撤销和重做。
- 已有文字、序号标注、标签气泡和水印统一为单击选中、双击编辑文字。选中序号标注时不会意外进入输入状态。
- 修复调整标注属性后的键盘焦点，并防止视频标注模式下未选中标注时按 Delete 误删视频片段。

感谢 @yuxino 完成本次修复。

macOS 和 Windows 安装版可在设置中更新；Windows 便携版请替换 ZIP。Linux 请运行 `sudo apt install ./kiri_1.6.16_amd64.deb`。macOS 保留 Kiri 的稳定签名身份，但未经 Apple 公证；如被拦截，请在**系统设置 → 隐私与安全性 → 仍要打开**中允许。Windows 安装包没有 Authenticode 签名。

已通过 macOS 交互验证及 Windows/Linux 自动检查；Intel Mac 真机、实体混合 DPI 显示器和所有 Linux 桌面/门户配置尚未完整验证。
