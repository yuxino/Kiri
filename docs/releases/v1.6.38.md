## English

- Fixed Windows video import and export failures caused by temporary files remaining open. Export errors now show clearer guidance; a saved copy can be opened again without exporting twice.
- Fixed annotation undo/redo leaving duplicate or reappearing marks that could prevent screenshot export.
- Keep OCR correction drafts when navigation is attempted or saving fails. Holding Enter after a text edit no longer accidentally saves and closes the editor.

## 中文

- 修复 Windows 视频导入、导出时临时文件未关闭导致的失败。导出错误提示更清晰，已保存的副本打开失败后可直接重试，无需再次导出。
- 修复标注撤销、重做后出现重复或重新冒出的标记，避免因此无法导出截图。
- 尝试切换页面或保存失败时保留 OCR 纠错草稿；文字编辑后长按 Enter 不再意外保存并关闭编辑器。
