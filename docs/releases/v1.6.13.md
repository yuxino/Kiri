## English

- Double-click inside a selected screenshot region to finish. After annotating, use the Select tool and double-click an unmarked area. Existing text stays editable; the saved-image editor keeps its explicit Save behavior.
- Pin screenshots directly from the completion card, beside Copy Again, to keep a reference image above other apps.
- Preserve the original Linux recording failure in diagnostic logs when an encoder shutdown would otherwise hide a cancelled screen-sharing request.

Thanks to @az6161311 for suggesting faster screenshot completion and pinning. Contributors to this release: @yuxino.

macOS and installed Windows builds use the signed, user-initiated updater. Windows Portable updates by replacing its ZIP. On Linux, install with `sudo apt install ./kiri_1.6.13_amd64.deb`; updates replace the `.deb`. macOS retains Kiri's stable local signing identity and is not Apple-notarized; if blocked, approve it through **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

Verification includes editor interaction regressions, installed Windows capture/pinning checks, isolated Ubuntu 24.04 X11 and GNOME Wayland checks, and macOS Universal package installation/launch. Windows native checks use Windows Server 2025; Windows 10 hardware, physical Linux hardware and multiple displays are not covered. See [feature previews and verification](https://github.com/yuxino/Kiri/pull/105#issuecomment-6078173798).

Full changelog: [v1.6.12 → v1.6.13](https://github.com/yuxino/Kiri/compare/v1.6.12...v1.6.13).

## 中文

- 在已选截图区域内双击即可完成截图。标注后，切回「选择」工具，在没有标注的地方双击完成。已有文字仍可继续编辑；二次图片编辑器保留显式保存方式。
- 截图完成卡片在「再次复制」旁新增「置顶」，可以直接把截图作为参考图留在其他应用上方。
- Linux 录屏诊断日志保留原始捕获错误，避免编码器结束时盖住取消屏幕共享授权的原因。

感谢 @az6161311 提出快捷完成截图和置顶的建议。本次发布贡献者：@yuxino。

macOS 和 Windows 安装版使用已签名、由用户逐步确认的更新流程；Windows 便携版通过替换 ZIP 更新。Linux 使用 `sudo apt install ./kiri_1.6.13_amd64.deb` 安装，更新时替换 `.deb`。macOS 沿用 Kiri 的稳定本地签名，未经过 Apple 公证；如果系统阻止打开，请在 **系统设置 → 隐私与安全性 → 仍要打开** 中确认。Windows 安装包未使用 Authenticode 签名。

验证覆盖编辑器交互回归、Windows 安装版截图与置顶、隔离 Ubuntu 24.04 X11 和 GNOME Wayland，以及 macOS Universal 包安装和启动。Windows 原生检查使用 Windows Server 2025，未覆盖 Windows 10 实机、Linux 实体硬件和多显示器。详见[功能预览与验证记录](https://github.com/yuxino/Kiri/pull/105#issuecomment-6078173798)。

完整更新记录：[v1.6.12 → v1.6.13](https://github.com/yuxino/Kiri/compare/v1.6.12...v1.6.13)。
