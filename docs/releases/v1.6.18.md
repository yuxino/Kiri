## English

- Check for updates when opening the main panel on macOS and installed Windows. **New update** appears beside Settings; downloading and installing remain explicit actions.
- Open new pinned screenshots at their original capture position and logical size. Existing references keep their adjusted position; Wayland placement remains controlled by the compositor.
- Add **Select captures** and **Select All**, with batch **Move to Trash** and **Restore** actions.
- Give Library, Text History, QR Favorites, Trash and Settings a consistent sidebar and workspace layout. Refine Settings and its language menu, remove redundant storage footers, and confirm Empty Trash inside the main window with matching toolbar buttons.
- Fix rapid annotation creation sharing selection identities, preserving independent editing and Undo/Redo.

Thanks to @yuxino for this release's changes, and to @az6161311 for the update, pin-placement and batch-cleanup suggestions.

Update through Settings on macOS and installed Windows. Replace the ZIP for Windows Portable. On Linux, install with `sudo apt install ./kiri_1.6.18_amd64.deb`. macOS retains Kiri's stable signing identity but is not Apple-notarized; if blocked, use **System Settings → Privacy & Security → Open Anyway**. Windows packages are not Authenticode-signed.

Automated regressions cover update discovery, batch selection, pin placement, annotation editing and seven-language layouts. Intel Mac hardware, physical mixed-DPI displays, native OS IME composition and all Linux desktop/portal configurations have not been fully tested.

## 中文

- macOS 和 Windows 安装版打开主面板时会检查更新，有新版本时在「设置」旁显示**有更新**；下载和安装仍由用户确认。
- 新截图置顶后保持原来的截图位置和逻辑尺寸，已有置顶图保留手动调整的位置；Wayland 中的位置仍由桌面合成器控制。
- 加入**多选素材**和**全选**入口，支持批量**移到回收站**和**恢复**。
- 统一素材库、文字、二维码收藏、回收站和设置的侧栏与页面布局，调整设置页和语言菜单，移除多余的存储提示；清空回收站的按钮尺寸与旁边一致，确认框放在主窗口内。
- 修复快速添加标注时选择标识重复的问题，保持各项独立编辑及撤销/重做正常。

感谢 @yuxino 完成本次改动，也感谢 @az6161311 对更新提醒、置顶位置和批量清理提出的建议。

macOS 和 Windows 安装版可在设置中更新；Windows 便携版请替换 ZIP。Linux 请运行 `sudo apt install ./kiri_1.6.18_amd64.deb`。macOS 保留 Kiri 的稳定签名身份，但未经 Apple 公证；如被拦截，请在**系统设置 → 隐私与安全性 → 仍要打开**中允许。Windows 安装包没有 Authenticode 签名。

自动回归覆盖更新检查、批量选择、置顶位置、标注编辑及七种语言布局；Intel Mac 真机、实体混合 DPI 显示器、原生输入法组合输入和所有 Linux 桌面/门户配置尚未完整验证。
