## English

- Pinned screenshots support scrolling and zoom, with long images opening at a readable width.
- Finish and pin a scrolling screenshot in one click.
- Make update notes and version information easier to read, and tidy up the sidebar.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download v1.6.31](https://github.com/yuxino/Kiri/releases/tag/v1.6.31). On Linux, install with `sudo apt install ./kiri_1.6.31_amd64.deb`.

macOS packages keep the stable self-signed identity and are not Apple notarized. First-time installation may require **Open Anyway** in **System Settings → Privacy & Security**.

macOS desktop interaction checks were not rerun for this release. Physical trackpad gestures and the reported Windows 10 dual-display setup remain unverified. Scrolling capture remains unavailable on Wayland.

Thanks @az6161311 for reporting [#188](https://github.com/yuxino/Kiri/issues/188).

## 中文

- 置顶截图支持滚动和缩放，长图按可读宽度打开。
- 滚动截图可一键完成并置顶。
- 更新说明和版本信息更易读，侧栏也做了整理。

macOS 和 Windows 安装版可在「设置 → 关于」更新；Linux 和 Windows 绿色版请[下载 v1.6.31](https://github.com/yuxino/Kiri/releases/tag/v1.6.31)。Linux 请使用 `sudo apt install ./kiri_1.6.31_amd64.deb` 安装。

macOS 安装包沿用稳定自签名，未经 Apple 公证；首次安装可能需要在「系统设置 → 隐私与安全性」选择「仍要打开」。

本次未复测 macOS 桌面交互。实体触控板手势和反馈者的 Windows 10 双屏环境仍待验证。Wayland 仍不支持滚动截图。

感谢 @az6161311 反馈 [#188](https://github.com/yuxino/Kiri/issues/188)。
