## English

- Keep the correct captures and actions visible when switching between Library, Trash and search results. Report failed favorite, trash and restore actions, and prevent duplicate favorite requests.
- Preserve text corrections during refreshes and failed saves. Canceling input-method composition no longer closes OCR forms or discards the correction.
- Wait for image stickers to load before exporting or closing a video, including stickers added while a save is pending. Playback shortcuts now respect focused controls and dialogs.
- Keep failed tag edits available for retry, preserve keyboard focus in menus and dialogs, and distinguish missing microphones from the system default.

macOS desktop checks were deferred to avoid interrupting an active computer session. Unsaved text corrections are not retained after leaving Text History or closing the library. Previously reported Windows scrolling-capture startup and full video-copy/deletion workflows remain under investigation; Wayland scrolling screenshots remain unavailable.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download the new package](https://github.com/yuxino/kiri/releases/latest). macOS packages keep the existing signing identity and are not notarized; first-time installation may require **Open Anyway** in System Settings → Privacy & Security.

## 中文

- 切换素材库、回收站和搜索结果时，保持素材与操作正确对应。收藏、移入回收站和恢复失败时显示提示，并防止重复提交收藏。
- 刷新和保存失败时保留文字校正草稿。取消输入法组词不再误关 OCR 配置窗口或丢弃校正内容。
- 视频导出或关闭前会等待图片贴纸加载完成，包括等待保存时新添加的贴纸。播放快捷键不再抢占按钮和对话框的按键。
- 标签修改失败后可保留内容重试，改善菜单和对话框的键盘焦点，并明确区分不可用的麦克风与系统默认设备。

为避免打断正在使用的电脑，本次未进行 macOS 桌面实测。离开「文字历史」或关闭素材库后，未保存的文字校正不会保留。此前反馈的 Windows 滚动截图启动及视频副本与删除的完整链路仍在排查；Wayland 仍不支持滚动截图。

macOS 和 Windows 安装版可在「设置 → 关于」更新；Linux 和 Windows 绿色版请[下载新版安装包](https://github.com/yuxino/kiri/releases/latest)。macOS 安装包沿用现有签名，未经 Apple 公证；首次安装可能需要在「系统设置 → 隐私与安全性」选择「仍要打开」。
