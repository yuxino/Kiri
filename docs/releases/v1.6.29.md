## English

- Improve scrolling-capture startup compatibility on Windows. When needed, the selection border and outer dimming stay hidden for that session so capture can continue.
- Restore focus to the original app after canceling or completing capture on Windows, preventing the library from appearing in front.

Windows Server 2025 checks passed. The Windows 10 dual-display case reported in [#152](https://github.com/yuxino/Kiri/issues/152) still needs confirmation from the reporter. macOS desktop interaction checks were not run for this release; Wayland scrolling screenshots remain unavailable.

Update in **Settings → About** on macOS and installed Windows builds. Linux and Windows Portable users can [download the new package](https://github.com/yuxino/kiri/releases/latest). macOS packages keep the existing signing identity and are not notarized; first-time installation may require **Open Anyway** in System Settings → Privacy & Security.

## 中文

- 改善 Windows 滚动截图的启动兼容性。必要时，该次截图的选区边框和外围遮罩会保持隐藏，让截图继续进行。
- Windows 取消或完成截图后，正确回到原来的应用，避免素材库出现在前台。

Windows Server 2025 检查已通过。[#152](https://github.com/yuxino/Kiri/issues/152) 反馈的 Windows 10 双屏环境仍待反馈者确认。本次未进行 macOS 桌面交互实测；Wayland 仍不支持滚动截图。

macOS 和 Windows 安装版可在「设置 → 关于」更新；Linux 和 Windows 绿色版请[下载新版安装包](https://github.com/yuxino/kiri/releases/latest)。macOS 安装包沿用现有签名，未经 Apple 公证；首次安装可能需要在「系统设置 → 隐私与安全性」选择「仍要打开」。
