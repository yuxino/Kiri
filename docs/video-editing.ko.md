# Kiri에서 동영상 편집하기

[简体中文](video-editing.zh-CN.md) · [English](video-editing.md) · [繁體中文](video-editing.zh-TW.md) · [日本語](video-editing.ja.md) · [Deutsch](video-editing.de.md) · **한국어** · [Français](video-editing.fr.md)

라이브러리에서 동영상을 열고 화면 위의 ‘자르기 및 내보내기’를 선택하세요. 이 안내는 현재 소스의 기능을 설명합니다. 설치한 버전에서 사용할 수 있는 기능은 해당 릴리스 안내를 확인하세요.

**Linux:** 원래 속도로 자르기, 클립 삭제와 순서 변경, 크기 프리셋, 원본 소리를 포함한 별도 MP4 내보내기를 지원합니다. 아래의 속도 변경, 주석, 스티커, 효과는 macOS/Windows에서만 사용할 수 있습니다. 지원하지 않는 작업을 포함한 저장 프로젝트는 변경하지 않고 읽기 전용으로 보관됩니다. 원본에는 정사각형 픽셀의 프로그레시브 동영상 트랙 하나와 최대 하나의 오디오 트랙이 있어야 하며 자막은 없어야 합니다. 필요한 코덱도 설치되어 있어야 합니다.

한 프로젝트는 원본 동영상 하나를 편집합니다. 클립으로 나눠 순서를 바꿀 수 있지만 여러 동영상을 가져와 하나의 타임라인으로 합칠 수는 없습니다.

## 녹화 또는 로컬 파일 가져오기

Kiri 녹화는 라이브러리에 나타납니다. 다른 파일은 ‘미디어 가져오기’를 선택하거나 PNG, JPEG, WebP, MP4, MOV 파일을 라이브러리로 드래그하세요. 이미지는 이미지 편집기에서, 동영상은 동영상 편집기에서 열립니다.

가져온 자료는 원래 이름을 유지하며 필터를 해제하면 라이브러리 맨 위에 나타납니다. 이미지는 방향을 반영하여 PNG로 변환하고 동영상은 복사합니다. 원본 파일은 바꾸지 않습니다. 한 번에 최대 32개 파일을 가져올 수 있습니다. 이미지는 디코더 메모리 제한 안에 들어야 하며 32MB 이하, 각 변 8192픽셀 이하이어야 합니다. 동영상은 최대 8GB입니다.

## 클립 자르기와 조정

- 타임라인을 클릭하여 재생 위치를 이동합니다. 클립 양끝을 드래그하여 자르거나, 재생 위치에서 분할하고, 불필요한 클립을 삭제하거나 드래그하여 순서를 바꿉니다.
- 클립을 선택하면 0.25–4배의 속도를 설정할 수 있습니다. 편집 미리보기와 내보낸 동영상에 모두 적용됩니다.
- 타임라인 높이를 조절할 수 있습니다. 추가 트랙은 타임라인 안에서 스크롤되어 영상 공간을 확보합니다.
- 자르기, 순서, 속도, 효과, 주석, 시간은 실행 취소와 다시 실행을 지원합니다. 삭제는 선택한 클립, 주석, 스티커 또는 효과에 적용됩니다.

재생 제어는 영상 밖에 있습니다. 탐색 막대는 키보드 입력과 마우스를 올렸을 때 시간 표시를 지원합니다. 드래그 중에는 일시 정지하고 놓으면 이전 재생 상태로 돌아갑니다. 재생 속도 프리셋과 사용자 지정 0.1–8배 설정은 보기용으로만 기억하며 내보내기 속도는 바꾸지 않습니다.

## 주석, 스티커와 효과 추가

편집기는 펜, 사각형, 선, 화살표, 편집 가능한 텍스트, 픽셀 및 흐림 모자이크 브러시를 제공합니다. 저장된 외관 설정을 사용하고 초기 색상은 빨강입니다. 동영상 모자이크는 자유롭게 그린 선이나 사각형, 타원 영역에 적용할 수 있습니다.

새로 그린 표시는 선택됩니다. 속성 영역에서 색상, 선 굵기 또는 모자이크 설정을 바꾸고 핸들을 드래그하여 모양을 조절하세요. ‘텍스트 편집’으로 내용을 바꿉니다. 글꼴, 색상, 배경은 즉시 적용되며 텍스트 트랙은 내용을 표시합니다. Esc는 현재 텍스트 편집을 취소합니다.

도구 모음에서 정적인 PNG, JPEG, WebP 스티커를 추가하세요. 투명도를 유지하고 비율을 바꾸지 않고 크기를 조절합니다. 주석, 스티커, 가리기 영역은 영상에서 직접 선택하고 드래그할 수 있습니다.

시간을 지정한 1.5–4배 확대와 진입·종료 조정, 흐림 또는 픽셀 가리기, 사용자 색상의 단색 가리기를 제공합니다. 확대한 이미지를 드래그하여 구도를 바꿀 수 있습니다. 강조 영역, 비율을 유지하는 자르기와 배경·여백, 시간과 색상을 지정하는 페이드인·아웃도 추가할 수 있습니다. 자주 쓰지 않는 설정은 ‘마무리’에 있습니다. 변경 사항은 즉시 표시됩니다.

각 주석, 스티커, 효과에는 개별 시간이 있습니다. 트랙 가운데를 드래그하여 시간을 이동하고 양끝으로 길이를 바꿉니다. 왼쪽 손잡이를 위아래로 드래그하여 레이어 순서를 바꾸며 가장자리에 가까워지면 목록이 스크롤됩니다. 위 오버레이는 아래 오버레이를 덮으며 미리보기와 내보내기에서 같습니다. 전체 이미지 조정은 별도의 순서 그룹에 있습니다. 시간 표시는 자르기와 속도 변경 후 완성된 동영상 타임라인을 따릅니다.

## 저장하고 나중에 계속하기

편집, 시간별 레이어, 스티커, 현재 위치는 로컬 라이브러리에 자동 저장됩니다. 원본 동영상을 다시 열어 계속하거나 Cmd/Ctrl+S로 즉시 저장하세요. 창을 닫으면 현재 텍스트 편집을 마치고 저장을 기다립니다. 저장에 실패하면 다시 시도하거나 계속 편집할 수 있습니다. 명시적으로 저장하지 않고 닫아도 마지막으로 성공한 프로젝트는 남습니다.

편집 가능한 프로젝트와 내보낸 MP4는 별도입니다. 내보내기는 원본 동영상을 바꾸지 않습니다.

## MP4 내보내기

오른쪽 위에서 ‘내보내기’를 선택하세요. 화질 메뉴에 실제 출력 크기가 표시됩니다.

| 설정 | 출력 크기 |
| --- | --- |
| 고화질 | 원본 크기 유지 |
| 일상적인 공유용 | 긴 변 최대 1080픽셀 |
| 작은 파일 | 긴 변 최대 720픽셀 |

작은 원본은 확대하지 않습니다. 파일 크기는 원본과 편집한 길이에 따라 달라집니다. 내보내기는 라이브러리에 새 사본을 만들며 인코딩 진행 상황을 표시합니다. 마지막 라이브러리 저장 전에는 취소할 수 있습니다. 취소하면 프로젝트는 유지되고 미완성 동영상은 추가되지 않습니다.

내보내기는 동기화된 소리를 유지합니다. Linux는 오디오를 48kHz 스테레오 AAC로 변환하고 동영상 방향을 적용하며 가변 프레임 속도와 오래 유지되는 프레임의 표시 시간을 보존합니다. macOS는 클립 속도를 바꿔도 음높이를 유지하고 Windows는 속도에 따라 음높이도 바뀝니다. Windows의 동영상 효과는 현재 회전 정보가 없는 원본이 필요합니다. Kiri 녹화는 이 조건을 충족합니다.
