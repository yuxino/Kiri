# 在 Kiri 中剪輯影片

[简体中文](video-editing.zh-CN.md) · [English](video-editing.md) · **繁體中文** · [日本語](video-editing.ja.md) · [Deutsch](video-editing.de.md) · [한국어](video-editing.ko.md) · [Français](video-editing.fr.md)

**繁體中文**

從素材庫打開影片，點選畫面上方的「剪輯與匯出」。本指南說明目前源碼中的功能；你安裝的版本有哪些操作，請以相應更新記錄為準。

**Linux：**支援正常速度的裁切、刪除與重排片段、輸出尺寸預設，並保留源聲音匯出獨立 MP4。下文的變速、標註、貼紙和特效仍僅支援 macOS/Windows；包含這些操作的已儲存專案在 Linux 上保持不變、只讀。輸入須為一條方形像素的逐行影片軌和至多一條音軌，不含字幕軌，且已安裝所需系統編解碼插件。Linux 會應用旋轉信息，將聲音轉換為 48 kHz 雙聲道 AAC；變影格率和靜態長影格保持原有顯示時序。

每個專案編輯一個源影片。可以將它分成多個片段並重新排序，但不能把匯入的多個影片合成一條時間軸。

## 匯入錄影或本地檔案

Kiri 錄影會儲存在素材庫中。其他檔案可通過「匯入素材」新增，也可以將 PNG、JPEG、WebP、MP4 或 MOV 檔案拖入素材庫。匯入的圖片使用圖片編輯器，影片使用影片編輯器。

匯入後保留原檔案名，清除篩選後顯示在素材庫頂部。圖片會校正方向並轉換為 PNG，影片複製到素材庫，原檔案不受影響。每次最多匯入 32 個檔案；圖片不能超過 32 MB、每邊 8192 像素，並須符合解碼內存限制；影片上限為 8 GB。

## 裁剪與調整片段

- 點選時間軸定位，拖動片段兩端裁剪，也可以在播放位置處分割、刪除不要的片段，或拖動片段重新排序。
- 選中片段後可設定 0.25～4 倍速度，預覽與匯出均生效。
- 時間軸高度可以調整；軌道較多時在時間軸內部滾動，為畫面留出空間。
- 裁剪、排序、變速、效果、標註和時間調整均支援復原、重做。刪除操作作用於目前選中的片段、標註、貼圖或效果。

播放控件位於畫面外，進度條支援鍵盤調整和懸停時間提示。拖動時暫停，鬆手還原此前的播放狀態。播放速度可選預設或輸入 0.1～8 倍，並會記住偏好；它只影響觀看，不改變匯出速度。

## 新增標註、貼圖和效果

剪輯器顯示截圖中的畫筆、矩形、直線、箭頭、可編輯文字，以及像素和模糊馬賽克筆刷。工具沿用已儲存的外觀設定，首次使用時預設紅色。影片馬賽克支援自由塗抹、矩形和橢圓覆蓋。

畫完後會選中新標註。可在屬性區修改顏色、粗細或馬賽克設定，拖動畫面上的手柄調整形狀。點選「編輯文字」修改內容；字號、顏色和背景實時生效，文字軌道顯示實際內容。Esc 取消目前文字編輯。

工具列可以新增本地 PNG、JPEG 或 WebP 靜態貼圖。貼圖保留透明背景，縮放時保持比例。標註、貼圖和遮擋都可以直接在畫面中選中並拖動。

效果包括按時段設定的 1.5～4 倍局部放大，可調整進入和退出時長；隱私遮擋可選模糊、像素或自定義顏色的純色。放大後可以拖動畫面調整取景。還可新增聚光強調、保持比例的裁切與背景留白，以及可調時長和顏色的淡入淡出。較少用的選項收在「畫面修飾」中，修改結果直接顯示在畫面上。

每個標註、貼圖和效果都有獨立時段。拖軌道中間移動時間，拖兩端調整時長，拖左側手柄上下調整圖層順序；接近列表邊緣時會自動滾動。上方疊加內容蓋住下方內容，預覽與匯出一致；整幅畫面的調整在單獨一組中排序。時段說明隨裁剪、變速更新，與成片時間軸一致。

## 儲存並繼續編輯

剪輯、效果軌道、貼圖和目前位置會自動儲存到本地素材庫。重新打開原始影片即可繼續，也可以按 Cmd/Ctrl+S 立即儲存。關閉視窗時會提交目前文字編輯並等待儲存；儲存失敗時可以重試或繼續編輯。明確選擇不儲存並關閉時，會保留最後一次成功儲存的專案。

可編輯專案與匯出的 MP4 分開儲存，匯出不會替換原始影片。

## 匯出 MP4

點選右上角的「匯出」。畫質菜單會顯示實際輸出尺寸：

| 設定 | 輸出尺寸 |
| --- | --- |
| 高畫質 | 保留原始尺寸 |
| 日常分享 | 最長邊不超過 1080 像素 |
| 小檔案 | 最長邊不超過 720 像素 |

不會放大小尺寸素材。檔案大小取決於原始影片和編輯後的時長。匯出會在素材庫中創建新副本，顯示編碼進度，並可在最後儲存到素材庫之前取消。取消會保留專案，不會向素材庫新增半成品。

匯出保留同步聲音。macOS 片段變速保持音高，Windows 變速會同時改變音高。Windows 的畫面效果目前要求源影片不含旋轉標記，Kiri 錄影符合此條件。
